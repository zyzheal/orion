## Current Status (2026-04-12)

### TASK-201 - 代码管理集成 (COMPLETED)

#### 已完成的工作

1. **统一适配器接口** (`src/services/code-repo/types.ts`)
   - `ICodeRepoAdapter` 接口定义，统一 GitLab/Gerrit/GitHub 操作
   - 完整的类型定义: Repository, Branch, Commit, PullRequest, Review, Webhook 等
   - WebhookEventType 枚举: code.pr.opened/merged/closed/updated/reviewed, code.push 等

2. **GitLab 适配器** (`src/services/code-repo/GitLabAdapter.ts`)
   - 仓库管理: getRepository, listRepositories
   - 分支管理: listBranches, getBranch, createBranch, deleteBranch, getBranchProtection
   - MR 管理: createPullRequest, getPullRequest, listPullRequests, merge, close, update
   - Review 管理: addReview, listReviews
   - Webhook 管理: createWebhook, listWebhooks, deleteWebhook
   - 数据映射: GitLab Project/Branch/MR/Note -> 统一类型

3. **Gerrit 适配器** (`src/services/code-repo/GerritAdapter.ts`)
   - Change 管理: createPullRequest, getPullRequest, listPullRequests, merge, close
   - Review 管理: addReview (支持 Code-Review score -2 to +2), listReviews
   - 分支管理: listBranches, getBranch, createBranch, deleteBranch
   - Webhook 管理: createWebhook, listWebhooks, deleteWebhook

4. **Branch Policy 服务** (`src/services/code-repo/BranchPolicyService.ts`)
   - 创建/更新/删除分支保护策略
   - 通配符分支模式匹配 (* 和 **)
   - 审批规则: 所需审批人数、审批人列表、作者自审限制、必需角色
   - 合并策略: merge_commit, squash_merge, rebase_merge, fast_forward
   - CI 检查验证: requiredChecks 列表检查
   - CODEOWNERS 审批要求
   - 管理员覆盖权限
   - 默认策略创建 (main, release/*, develop)

5. **Code Ownership 服务** (`src/services/code-repo/CodeOwnershipService.ts`)
   - CODEOWNERS 文件解析 (支持注释、空行、@ 前缀、行内注释)
   - 文件路径模式匹配 (精确匹配、目录匹配、扩展名匹配、路径匹配)
   - 审批人推荐: 基于变更文件路径推荐 CODEOWNERS
   - PR 审批人汇总: 分析所有变更文件，汇总需要的审批人
   - 文件格式验证

6. **Webhook 服务** (`src/services/code-repo/WebhookService.ts`)
   - GitLab Webhook 处理: merge_request, push, note 等事件
   - Gerrit Webhook 处理: change-merged, change-created, comment-added 等
   - GitHub Webhook 处理: pull_request opened/closed 等
   - 统一事件格式: CodeRepoWebhookPayload
   - NATS 事件发布: code.pr.opened, code.pr.merged, code.pr.closed 等
   - Webhook 签名验证 (GitLab Token, GitHub HMAC-SHA256)
   - 事件日志记录与查询

7. **API 控制器** (4个)
   - `CodeRepoController.ts`: 仓库、分支、PR/MR、Review 管理
   - `BranchPolicyController.ts`: 分支保护策略 CRUD + 合并检查
   - `CodeOwnershipController.ts`: CODEOWNERS 管理 + 审批人推荐
   - `WebhookController.ts`: Webhook 接收 + 事件日志

8. **API 路由** (`src/api/code-repo-routes.ts`)
   - 前缀: `/api/v1/code-repo`
   - 40+ REST 端点，已集成到主路由

9. **路由端点清单**:
   - `GET /adapters` - 已注册适配器列表
   - `GET /:adapterId/repositories` - 仓库列表
   - `GET /:adapterId/repository` - 仓库详情
   - `GET /:adapterId/:repoId/branches` - 分支列表
   - `GET /:adapterId/:repoId/branches/:branchName` - 分支详情
   - `POST /:adapterId/:repoId/branches` - 创建分支
   - `DELETE /:adapterId/:repoId/branches/:branchName` - 删除分支
   - `GET /:adapterId/:repoId/pull-requests` - PR/MR 列表
   - `GET /:adapterId/:repoId/pull-requests/:prId` - PR/MR 详情
   - `POST /:adapterId/:repoId/pull-requests` - 创建 PR/MR
   - `POST /:adapterId/:repoId/pull-requests/:prId/merge` - 合并 PR/MR
   - `POST /:adapterId/:repoId/pull-requests/:prId/close` - 关闭 PR/MR
   - `GET /:adapterId/:repoId/pull-requests/:prId/reviews` - Reviews 列表
   - `POST /:adapterId/:repoId/pull-requests/:prId/reviews` - 添加 Review
   - `POST /branch-policies` - 创建分支保护策略
   - `GET /branch-policies/:id` - 策略详情
   - `GET /branch-policies/repo/:repoId` - 仓库所有策略
   - `PUT /branch-policies/:id` - 更新策略
   - `DELETE /branch-policies/:id` - 删除策略
   - `GET /branch-policies/match` - 匹配分支策略
   - `POST /branch-policies/check-merge` - 检查合并可行性
   - `POST /branch-policies/defaults/:repoId` - 创建默认策略
   - `POST /code-owners` - 注册 CODEOWNERS 文件
   - `GET /code-owners/:repoId` - 获取 CODEOWNERS 文件
   - `DELETE /code-owners/:repoId` - 删除 CODEOWNERS 文件
   - `POST /code-owners/validate` - 验证 CODEOWNERS 格式
   - `POST /code-owners/recommend` - 获取审批人推荐
   - `POST /code-owners/approvers` - 获取 PR 所需审批人
   - `POST /webhooks/gitlab` - GitLab Webhook
   - `POST /webhooks/gerrit` - Gerrit Webhook
   - `POST /webhooks/github` - GitHub Webhook
   - `GET /webhooks/logs` - 事件日志
   - `POST /webhooks/secret` - 注册 Webhook 密钥
