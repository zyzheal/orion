## 2. Key 命名规范

### 2.1 命名格式

```
<page>.<component>.<action|element>
```

**示例**：
- `triage.overview.oncall.active`（Triage Overview 值班中）
- `triage.queue.group.critical`（Triage Queue 分组头 Critical）
- `triage.action.ack`（Triage 确认动作）
- `error.code.triage_item_not_found`（错误码 Triage 项不存在）

### 2.2 命名规则

1. **全小写** + **下划线分隔单词**
2. **层级最多 4 层**（page.component.element.modifier）
3. **动作**用 `action` 前缀（`action.ack`, `action.dismiss`）
4. **错误码**用 `error.code` 前缀（`error.code.<CODE_LOWER>`）
5. **状态**用 `status` 前缀（`status.loading`, `status.empty`）
6. **禁止**：
   - 直接使用英文原文（如 `Save` 应该是 `action.save`）
   - 硬编码字符串（除非在常量定义中）
   - 变量插值在 key 里（用 i18next `{{variable}}` 语法）

### 5.2 加载方式

**动态加载**（避免 bundle size 爆炸）：

```typescript
// i18n/index.ts
import i18n from 'i18next'
import LanguageDetector from 'i18next-browser-languagedetector'

i18n
  .use(LanguageDetector)
  .init({
    fallbackLng: 'en-US',
    nsSeparator: ':',
    keySeparator: '.',
    resources: {
      'zh-CN': {
        common: translate('common'),
        triage: () => import('./locales/zh-CN/triage.json'),
        'user-roles': () => import('./locales/zh-CN/user-roles.json'),
        dnd: () => import('./locales/zh-CN/dnd.json'),
        commands: () => import('./locales/zh-CN/commands.json'),
        hotkeys: () => import('./locales/zh-CN/hotkeys.json'),
        errors: () => import('./locales/zh-CN/errors.json'),
      },
      'en-US': { /* similar */ }
    },
    defaultNS: 'common',
  })
```

## 6. 使用规范

### 6.1 组件内使用

```tsx
import { useTranslation } from 'i18next'

export function TriagePage() {
  const { t } = useTranslation(['triage', 'common'])
  
  return (
    <div>
      <h1>{t('triage:title')}</h1>
      <button onClick={ack}>{t('triage:action.ack')}</button>
      <span>{t('triage:overview.oncall.remaining', { duration: '2h 30m' })}</span>
    </div>
  )
}
```

## 7. 检查清单

### 7.1 代码审查清单

- [ ] 所有用户可见字符串通过 `t()` 获取（不允许硬编码）
- [ ] 所有新页面有对应 JSON 文件（zh-CN + en-US）
- [ ] 所有错误码在 `errors.json` 中定义
- [ ] Key 命名符合规范（小写 + 下划线）
- [ ] 变量插值使用 `{{variable}}` 语法
- [ ] 有 fallback 默认语言（`en-US`）

