# Orion 前端系统 — 深度评审提示词 (2026-08-25)

## 评审目标
对 Orion 前端系统（React + TypeScript + Ant Design 5 + Vite）进行全面深度评审，
覆盖代码质量、架构设计、性能、安全、TypeScript 类型安全、测试覆盖、API 交互、
UI/UX 一致性等所有维度，产出系统性完善方案并保存到本地。

## 评审维度（10 大维度）

1. **代码质量** — 死代码/冗余逻辑/错误处理/副作用管理
2. **架构设计** — 目录结构/组件分层/状态管理/路由设计
3. **性能** — 渲染优化/虚拟化/代码分割/请求优化
4. **安全** — XSS/CSRF/权限校验/敏感信息
5. **TypeScript 类型安全** — any 使用/类型收窄/公共类型
6. **可维护性** — 注释/命名/抽象复用/魔法数字
7. **UI/UX 一致性** — Token 覆盖/暗黑模式/响应式/空状态/无障碍
8. **测试** — 单元/组件/集成/CI
9. **API 交互** — 格式统一/错误处理/分页搜索
10. **部署与运维** — 构建/环境变量/监控

## 输出格式
- 按模块组织，问题分级 P0/P1/P2/P3
- 每个问题：现象 → 影响 → 文件位置 → 修复建议 → 代码示例
- 最后汇总改进路线图（按优先级排序）
