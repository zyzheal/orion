🎯 对接策略

1

策略 A：逐域对接（推荐）

按功能域分组，先完成一个域的所有页面对接，再进入下一个域。好处是每个域可独立验证，风险分散。

2

策略 B：先易后难

先对接 B 级页面（12 个，8-12 天），快速见效；再处理 C 级页面。

3

策略 C：后端先行

先补齐 ~25 个缺失的后端 API，再统一前端对接。避免前端等后端的情况。
