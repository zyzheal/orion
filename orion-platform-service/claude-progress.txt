## Previous Session (2026-05-17)

### Completed: SSO/OIDC Integration for Enterprise Authentication

Added OpenID Connect (OIDC) support as a secondary authentication method
alongside the existing local username/password + JWT system.

#### Changes Made
- **Added dependency**: `openid-client@^6.8.4` (latest v6 API, oauth4webapi-based)
- **Created** `src/services/auth/SsoService.ts`:
  - OIDC discovery via `discovery()` — dynamically reads provider metadata
  - Authorization URL generation with PKCE-style nonce + state (CSRF protection)
  - Callback handling with `authorizationCodeGrant()` — exchanges code for tokens
  - ID token claims extraction (sub, email, name, groups, roles)
  - In-memory state store with automatic 10-minute cleanup
  - Safe initialization — platform starts even if SSO is misconfigured
  - `getConfig()` strips clientSecret for safe admin UI exposure
- **Created** `src/api/sso-routes.ts`:
  - `GET /api/v1/auth/sso/login` — redirects to SSO provider
  - `GET /api/v1/auth/sso/callback` — handles OAuth2 callback, auto-provisions user, issues JWT
  - `GET /api/v1/auth/sso/status` — returns SSO configuration status (for login page)
  - `GET /api/v1/auth/sso/config` — returns SSO config details (for admin settings)
  - Auto-provisioning: creates new user on first SSO login with role mapping
  - Links existing local accounts: updates `sso_sub` if user registered locally first
- **Created** `src/db/migrations/159_sso_support.sql`:
  - Adds `sso_sub VARCHAR(255)` column to `users` table
  - Creates index `idx_users_sso_sub` for efficient SSO lookups
- **Created** `src/db/migrations/159_rollback_sso_support.sql`:
  - Drops index and column for rollback
- **Modified** `src/services/auth/index.ts`: exports `SsoService`, `SsoConfig`, `SsoUserProfile`
- **Modified** `src/app.ts`: registers SSO routes under `/api/v1/auth` prefix

#### Environment Variables

| `SSO_ISSUER_URL` | Yes | OIDC issuer URL (e.g., `https://accounts.google.com`) |
| `SSO_CLIENT_ID` | Yes | OAuth2 client ID |

#### Bug Fixes During Development

1. **analyzeDependencies**: `packageJson.dependencies` 是 `Record<string, string>`，不能直接展开。修复：使用 `Object.entries()` 转换为 `[string, string][]` 后展开。
2. **serializeSbom**: 当 `purl` 不存在时，`externalRefs` 应为 `undefined` 而非空数组 `[]`。修复：使用条件展开 `...(comp.purl ? { externalRefs: [...] } : {})`。
3. **checkCompliance**: 默认策略只检查 `blockedLicenseCategories`，未检查 `isApproved`。修复：对 `!isApproved` 的许可证直接标记违规（不限 category）。
4. **totalNodes**: 根节点未加入 `allNodes`，导致无依赖时 `totalNodes` 为 0。修复：初始化时将 root 加入 `allNodes`。
