## 快速开始（5 分钟）

### 前提条件

| 要求 | 说明 |
|------|------|
| Docker | 20.10+ 或 Docker Desktop |
| 或 NATS 二进制 | v2.10+ |
| 内存 | 最低 512MB |
| 磁盘 | 最低 1GB |

### 一键启动（推荐）

```bash
# 方式 1：Docker 快速启动
docker run -d --name nats -p 4222:4222 -p 8222:8222 \
  nats:2.10 \
  --jetstream --store_dir /data

# 验证
docker ps | grep nats

# 测试发布/订阅
docker exec -it nats nats sub 'test.>' --count 3
# 另开终端执行：
docker exec -it nats nats pub test.hello "Hello NATS"
```

### 使用项目中的 Docker Compose

```bash
# 进入部署目录
cd orion-api-gateway/infra/nats

# 启动 3 节点集群
docker-compose up -d

# 查看状态
docker-compose ps

# 查看日志
docker-compose logs -f nats-1

# 停止
docker-compose down
```

## Docker 部署（推荐）

### 方式 1：单机开发版

```bash
# 启动
docker run -d --name nats-dev \
  -p 4222:4222 \
  -p 8222:8222 \
  -v nats-data:/data \
  nats:2.10 \
  --jetstream \
  --store_dir /data

# 验证
docker exec -it nats-dev nats server info

# 停止
docker stop nats-dev
docker rm nats-dev
```

### 方式 2：3 节点集群（生产模拟）

**步骤 1：创建配置文件**

```bash
cd orion-api-gateway/infra/nats

# 创建配置目录
mkdir -p config

# NATS 节点 1 配置
cat > config/nats-1.conf << 'EOF'
server_name: nats-1
port: 4222
http_port: 8222

jetstream {
  max_mem_store: 1GB
  max_file_store: 10GB
  store_dir: /data
}

cluster {
  name: ORION
  listen: 0.0.0.0:6222
  routes = [
    nats://nats-2:6222
    nats://nats-3:6222
  ]
}
EOF

# NATS 节点 2 配置
cat > config/nats-2.conf << 'EOF'
server_name: nats-2
port: 4222
http_port: 8222

jetstream {
  max_mem_store: 1GB
  max_file_store: 10GB
  store_dir: /data
}

cluster {
  name: ORION
  listen: 0.0.0.0:6222
  routes = [
    nats://nats-1:6222
    nats://nats-3:6222
  ]
}
EOF

# NATS 节点 3 配置
cat > config/nats-3.conf << 'EOF'
server_name: nats-3
port: 4222
http_port: 8222

jetstream {
  max_mem_store: 1GB
  max_file_store: 10GB
  store_dir: /data
}

cluster {
  name: ORION
  listen: 0.0.0.0:6222
  routes = [
    nats://nats-1:6222
    nats://nats-2:6222
  ]
}
EOF
```

**步骤 2：创建 docker-compose.yml**

```yaml
version: '3.8'

services:
  nats-1:
    image: nats:2.10-alpine
    container_name: nats-server-1
    hostname: nats-1
    ports:
      - "4222:4222"
      - "8222:8222"
      - "6222:6222"
    command: ["-c", "/etc/nats/nats.conf", "--jetstream"]
    volumes:
      - ./config/nats-1.conf:/etc/nats/nats.conf
      - nats-data-1:/data
    networks:
      - orion-network
    healthcheck:
      test: ["CMD", "nats-server", "-sl", "ldm=/var/run/nats/nats.pid"]
      interval: 10s
      timeout: 5s
      retries: 3
    restart: unless-stopped

  nats-2:
    image: nats:2.10-alpine
    container_name: nats-server-2
    hostname: nats-2
    ports:
      - "4223:4222"
      - "8223:8222"
      - "6223:6222"
    command: ["-c", "/etc/nats/nats.conf", "--jetstream"]
    volumes:
      - ./config/nats-2.conf:/etc/nats/nats.conf
      - nats-data-2:/data
    networks:
      - orion-network
    healthcheck:
      test: ["CMD", "nats-server", "-sl", "ldm=/var/run/nats/nats.pid"]
      interval: 10s
      timeout: 5s
      retries: 3
    restart: unless-stopped

  nats-3:
    image: nats:2.10-alpine
    container_name: nats-server-3
    hostname: nats-3
    ports:
      - "4224:4222"
      - "8224:8222"
      - "6224:6222"
    command: ["-c", "/etc/nats/nats.conf", "--jetstream"]
    volumes:
      - ./config/nats-3.conf:/etc/nats/nats.conf
      - nats-data-3:/data
    networks:
      - orion-network
    healthcheck:
      test: ["CMD", "nats-server", "-sl", "ldm=/var/run/nats/nats.pid"]
      interval: 10s
      timeout: 5s
      retries: 3
    restart: unless-stopped

networks:
  orion-network:
    driver: bridge

volumes:
  nats-data-1:
  nats-data-2:
  nats-data-3:
```

**步骤 3：启动集群**

```bash
# 启动
docker-compose up -d

# 等待集群就绪（约 10 秒）
sleep 10

# 查看状态
docker-compose ps

# 查看集群信息
docker exec -it nats-server-1 nats server info

# 查看 JetStream 状态
docker exec -it nats-server-1 nats stream ls
```

## 二进制部署

### Linux

```bash
# 1. 下载
cd /tmp
curl -LO https://github.com/nats-io/nats-server/releases/download/v2.10.22/nats-server-v2.10.22-linux-amd64.tar.gz

# 2. 解压
tar xzf nats-server-v2.10.22-linux-amd64.tar.gz
cd nats-server-v2.10.22-linux-amd64

# 3. 移动到系统路径
sudo mv nats-server /usr/local/bin/

# 4. 验证安装
nats-server --version

# 5. 创建配置目录
sudo mkdir -p /etc/nats /data/nats

# 6. 创建配置文件
sudo cat > /etc/nats/nats.conf << 'EOF'
server_name: nats-prod
port: 4222
http_port: 8222

jetstream {
  max_mem_store: 4GB
  max_file_store: 100GB
  store_dir: /data/nats
}

# 认证（可选）
authorization {
  users: [
    {
      user: admin
      password: your_secure_password
    }
  ]
}
EOF

# 7. 启动（前台测试）
sudo nats-server -c /etc/nats/nats.conf --jetstream

# 8. 后台运行（systemd）
sudo cat > /etc/systemd/system/nats-server.service << 'EOF'
[Unit]
Description=NATS Server
After=network.target

[Service]
Type=simple
User=nats
ExecStart=/usr/local/bin/nats-server -c /etc/nats/nats.conf --jetstream
Restart=on-failure
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
EOF

# 创建用户
sudo useradd -r -s /sbin/nologin nats
sudo chown -R nats:nats /data/nats

# 启动服务
sudo systemctl daemon-reload
sudo systemctl enable nats-server
sudo systemctl start nats-server
sudo systemctl status nats-server
```

### macOS

```bash
# 1. 使用 Homebrew 安装
brew install nats-io/nats-server/nats-server

# 2. 启动
nats-server --jetstream

# 3. 或使用配置文件
mkdir -p /usr/local/etc/nats
cat > /usr/local/etc/nats/nats.conf << 'EOF'
server_name: nats-mac
port: 4222
http_port: 8222
jetstream {
  store_dir: /tmp/nats-js
}
EOF

nats-server -c /usr/local/etc/nats/nats.conf --jetstream

# 4. 后台运行（launchd）
cat > ~/Library/LaunchAgents/io.nats.server.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" 
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>io.nats.server</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/local/bin/nats-server</string>
    <string>-c</string>
    <string>/usr/local/etc/nats/nats.conf</string>
    <string>--jetstream</string>
  </array>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <true/>
</dict>
</plist>
EOF

launchctl load ~/Library/LaunchAgents/io.nats.server.plist
```

### Windows

## 配置文件详解

### 完整配置示例

```conf
# /etc/nats/nats.conf

# ==================== 基础配置 ====================
server_name: nats-orion        # 服务器名称
port: 4222                      # 客户端连接端口
http_port: 8222                 # 监控端口

# ==================== JetStream 配置 ====================
jetstream {
  max_mem_store: 4GB           # 最大内存存储
  max_file_store: 100GB        # 最大文件存储
  store_dir: /data/nats        # 存储目录
}

# ==================== Cluster 配置 ====================
cluster {
  name: ORION                           # 集群名称
  listen: 0.0.0.0:6222                  # 集群监听地址
  routes = [                            # 集群路由
    nats://nats-2:6222
    nats://nats-3:6222
  ]
  
  # 集群认证（可选）
  authorization {
    user: cluster_user
    password: cluster_secure_password
  }
}

# ==================== Gateway 配置（跨数据中心） ====================
#gateway {
#  name: ORION-GW
#  listen: 0.0.0.0:7222
#  gateways: [
#    {
#      name: ORION-DC2
#      url: nats://gateway-remote:7222
#    }
#  ]
#}

# ==================== 认证配置 ====================
authorization {
  # 用户列表
  users: [
    {
      user: admin
      password: admin_secure_password_2026
      permissions: {
        publish: ">"
        subscribe: ">"
      }
    },
    {
      user: service
      password: service_secure_password_2026
      permissions: {
        publish: "orion.>"
        subscribe: "orion.>"
      }
    },
    {
      user: readonly
      password: readonly_secure_password_2026
      permissions: {
        subscribe: ">"
      }
    }
  ]
  
  # 默认权限（可选）
  default_permissions: {
    publish: ">"
    subscribe: ">"
  }
}

# ==================== TLS 配置（可选） ====================
#tls {
#  cert_file: /etc/nats/certs/server-cert.pem
#  key_file: /etc/nats/certs/server-key.pem
#  ca_file: /etc/nats/certs/ca-cert.pem
#  verify: true
#  cipher_suites: [
#    "TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256",
#    "TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384"
#  ]
#}

# ==================== 日志配置 ====================
logtime: true                   # 日志时间戳
debug: false                    # 调试模式（生产环境关闭）
trace: false                    # 跟踪模式（生产环境关闭）
log_file: /var/log/nats/nats.log

# ==================== 性能调优 ====================
max_connections: 10000          # 最大连接数
max_payload: 8MB                # 最大消息负载
max_pending: 64MB               # 最大待处理数据
write_deadline: "2s"            # 写入超时
```

### 配置验证

```bash
# 验证配置文件语法
nats-server -c /etc/nats/nats.conf -t

# 输出示例:
# [INF] 配置文件语法正确
```

### 2. 发布/订阅测试

```bash
# 终端 1：订阅
nats sub 'test.>' --server nats://localhost:4222

# 终端 2：发布
nats pub test.hello "Hello NATS" --server nats://localhost:4222
nats pub test.world "World message" --server nats://localhost:4222

```

### 3. JetStream 测试

```bash
# 创建 Stream
nats stream create ORION-TEST \
  --subjects="test.*" \
  --storage=file \
  --retention=limits \
  --replicas=1 \
  --max-msgs=1000

# 发布消息
nats pub test.event '{"name": "test1"}'
nats pub test.event '{"name": "test2"}'

# 查看 Stream 信息
nats stream info ORION-TEST

# 消费消息
nats consumer add ORION-TEST test-consumer \
  --filter=test.event \
  --deliver=all \
  --ack=explicit

# 读取消息
nats consumer next ORION-TEST test-consumer
```

## 常见问题

### Q1: 启动失败 "address already in use"

```bash
# 检查端口占用
lsof -i :4222
lsof -i :8222

# 杀死占用进程
kill -9 $(lsof -t -i:4222)

# 或更改端口
nats-server --port 5222
```

### Q2: JetStream 无法启动

```bash
# 检查存储目录权限
ls -la /data/nats
chmod 755 /data/nats
chown nats:nats /data/nats

# 清理旧数据
rm -rf /data/nats/*
nats-server --jetstream --store_dir /data/nats
```

### Q3: 集群节点无法连接

```bash
# 检查防火墙
sudo ufw allow 6222/tcp
sudo ufw allow 4222/tcp
sudo ufw allow 8222/tcp

# 检查路由配置
cat /etc/nats/nats.conf | grep routes

# 重启集群
docker-compose restart
```

### Q4: 内存占用过高

```bash
# 限制 JetStream 内存
jetstream {
  max_mem_store: 512MB
}

# 或重启服务
docker restart nats-server-1
```

### Q5: 消息持久化丢失

```bash
# 确保使用持久化存储
docker run -v nats-data:/data nats:2.10 --jetstream --store_dir /data

# 验证 Stream 配置
nats stream info ORION-TEST
# 确认 storage: file
```
