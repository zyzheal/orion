## 三、文档命名规范

### 3.1 文件命名规则

```
格式: {类型前缀}-{简短描述}.md

ADR:          ADR-{NNN}-{描述}.md
              示例: ADR-010-事件格式标准化.md

设计文档:     {领域}-{描述}.md
              示例: ai-模型治理设计.md

评审报告:     review-{模块}.md
              示例: review-pipeline.md

高保真设计:   {NN}-{页面}.md
              示例: 01-pipeline-list.md

规范/指南:    {领域}-guide.md 或 {领域}-规范.md
              示例: api-设计规范.md
```

### 3.2 目录命名

- 全小写英文 + 连字符
- 使用领域缩写: `ai/`, `api/`, `db/`, `sre/`, `qa/`

### 3.3 禁止事项

- ❌ 不使用空格，用连字符 `-` 或下划线 `_`
- ❌ 不使用中文目录名（避免跨平台兼容问题）
- ❌ 不在文件名中使用特殊字符 `<>:"/\|?*`

## 四、统一 Frontmatter

所有文档必须添加 YAML frontmatter:

```yaml
---
title: "文档标题"
type: design | adr | review | spec | guide
domain: architecture | ai | api | db | frontend | security | sre | qa | ...
status: draft | review | approved | deprecated
version: "1.0"
created: "2026-04-10"
updated: "2026-04-10"
author: "作者"
tags: [tag1, tag2]
related:
  - "docs/adr/ADR-005-xxx.md"
  - "docs/ai/xxx.md"
---
```

## 五、ADR 管理规范

## 六、交叉引用规范

### 6.1 引用格式

```markdown
<!-- 文档内引用其他文档 -->
> 📎 参见: [ADR-005 数据库选型](../docs/adr/ADR-005-数据库选型决策.md)

<!-- 引用模块 -->
> 🔗 模块: [M28 Orion-Knowledge](../docs/knowledge/Orion-Knowledge 微服务改造方案.md)
```

高频被引用的文档底部维护反向链接:

```markdown
## 📌 被以下文档引用

- [架构重构设计](../docs/architecture/架构重构设计.md)
```

```markdown

### Added
- `docs/xxx/xxx.md` — 描述

### Changed
- `docs/xxx/xxx.md` — 变更描述

### Deprecated
```


## 九、文档生命周期

```
draft ──review──→ approved ──major change──→ deprecated
  │                  │
  │                  └──minor change──→ approved (version bump)
  │
  └── abandon ──→ removed (after 30 days)
```

| 状态 | 含义 | 权限 |
|------|------|------|
| draft | 编写中 | 自由编辑 |
| review | 评审中 | 可评论，作者修改 |
| approved | 已批准 | 只读，变更需评审 |
| deprecated | 已废弃 | 归档保留，不再维护 |

## 十一、工具支持

### 11.1 文档检查脚本

```bash
#!/bin/bash
# tools/check-docs.sh — 文档健康检查

echo "=== 文档健康检查 ==="

# 检查无 frontmatter 的文档
echo "1. 缺少 frontmatter 的文档:"
for f in $(find docs/ -name "*.md"); do
  if ! head -1 "$f" | grep -q "^---$"; then
    echo "   ❌ $f"
  fi
done

# 检查 ADR 编号连续性
echo "2. ADR 编号:"
ls docs/adr/ADR-*.md | sed 's/.*ADR-0*\([0-9]*\).*/\1/' | sort -n

# 检查空目录
echo "3. 空目录:"
find docs/ -type d -empty

# 统计
echo "4. 统计:"
echo "   总文档: $(find . -name '*.md' -not -path './orion-*' -not -path './archive/*' | wc -l)"
echo "   ADR:    $(ls docs/adr/ADR-*.md 2>/dev/null | wc -l)"
echo "   Draft:  $(grep -rl 'status: draft' docs/ 2>/dev/null | wc -l)"
```

### 11.2 断裂链接检查

```bash
#!/bin/bash
# tools/check-links.sh — 检查断裂的文档链接

echo "=== 断裂链接检查 ==="
grep -roh '\[.*\](\.\.*/[^)]*\.md)' docs/ | \
  sed 's/.*](\(.*\))/\1/' | sort -u | \
  while read link; do
    if [ ! -f "$(dirname "$link")/$(basename "$link")" ] 2>/dev/null; then
      echo "   ❌ 断裂: $link"
    fi
  done
```
