## 2. PageRank 根因定位算法

### 2.1 算法原理

在服务调用图上运行 Personalized PageRank，从异常服务出发，反向追溯找到"影响力源头"。

```python
import networkx as nx

def find_root_cause(service_graph: nx.DiGraph, 
                    anomaly_scores: dict) -> list[tuple[str, float]]:
    """
    在服务调用图上，结合异常评分做 Personalized PageRank
    找到最可能是根因的节点
    
    关键: 在反向图上跑 (从症状追溯到根因)
    """
    # 构建 personalization 向量 (异常服务作为种子)
    personalization = {
        node: anomaly_scores.get(node, 0.01) 
        for node in service_graph.nodes()
    }
    
    # 反向图: 如果 A 调用 B，反向后 B 指向 A
    # 这样 PageRank 分数高的节点就是"影响源头"
    reverse_graph = service_graph.reverse()
    
    scores = nx.pagerank(
        reverse_graph,
        personalization=personalization,
        alpha=0.85,      # 阻尼系数
        max_iter=100,
        tol=1e-6,
    )
    
    # 按分数降序排列
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)

# 输出示例:
# [
#   ("payment-db", 0.35),     # ← 最可能的根因
#   ("payment-service", 0.22),
#   ("order-service", 0.15),
#   ("api-gateway", 0.08),
#   ("user-service", 0.05),
# ]
```

## 3. 动态基线异常检测

### 3.1 算法实现

```python
import numpy as np
from collections import deque

class DynamicBaselineDetector:
    """
    不依赖静态阈值，AI 学习正常行为自动发现异常
    """
    
    def __init__(self, window_size=288):  # 24h × 12 (5分钟粒度)
        self.history = deque(maxlen=window_size)
        self.trend_window = 12  # 1 小时趋势窗口
    
    def detect(self, value: float, timestamp: str) -> dict:
        self.history.append(value)
        
        if len(self.history) < 24:  # 至少 2 小时数据
            return {"anomaly": False, "reason": "数据不足"}
        
        # 1. Z-Score 检测 (偏离正常程度)
        mean = np.mean(self.history)
        std = np.std(self.history) + 1e-8  # 防止除零
        z_score = abs(value - mean) / std
        
        # 2. 趋势检测 (是否持续上升/下降)
        recent = list(self.history)[-self.trend_window:]
        if len(recent) >= 6:
            trend = np.polyfit(range(len(recent)), recent, 1)[0]
            trend_significant = abs(trend) > std * 0.5
        else:
            trend = 0
            trend_significant = False
        
        # 3. 突跃检测 (与前值比较)
        if len(self.history) >= 2:
            jump = abs(value - self.history[-2])
            jump_significant = jump > std * 2
        else:
            jump = 0
            jump_significant = False
        
        # 综合判断
        is_anomaly = (
            z_score > 3.0 or  # 偏离超过 3 个标准差
            (z_score > 2.0 and trend_significant) or  # 偏离 + 趋势
            jump_significant  # 突跃
        )
        
        return {
            "anomaly": is_anomaly,
            "z_score": round(z_score, 2),
            "baseline": round(mean, 2),
            "std": round(std, 2),
            "deviation": round(value - mean, 2),
            "trend": round(trend, 4),
            "jump": round(jump, 2),
            "timestamp": timestamp,
        }
```

### 3.2 对比静态阈值

| 场景 | 静态阈值 | 动态基线 |
|------|---------|---------|
| 凌晨流量低谷 | 可能误报 (低于阈值) | ✅ 学习低谷模式，不误报 |
| 工作日高峰 | 可能漏报 (高于阈值) | ✅ 学习高峰模式，正常不报 |
| 缓慢劣化 | ❌ 无法检测 (未超阈值) | ✅ 趋势检测发现 |
| 突发故障 | ✅ 可以检测 | ✅ 突跃检测发现 |
| 季节性变化 | ❌ 需要手动调阈值 | ✅ 自动学习周期模式 |

## 4. Thompson Sampling 灰度优化

### 4.1 算法实现

```python
import numpy as np

class ThompsonSamplingCanary:
    """
    用 Thompson Sampling 自动找到最优灰度节奏
    每个灰度阶段 = 一个"arm"
    reward = 该阶段的成功率
    """
    
    def __init__(self, stages=[5, 10, 20, 40, 100]):
        self.stages = stages
        # Beta 分布先验: α=成功数+1, β=失败数+1
        self.successes = np.ones(len(stages))
        self.failures = np.ones(len(stages))
    
    def select_next_stage(self) -> int:
        """选择下一个灰度阶段"""
        # 从每个阶段的 Beta 分布采样
        samples = np.random.beta(self.successes, self.failures)
        # 选择期望成功率最高的阶段
        best_idx = np.argmax(samples)
        return self.stages[best_idx]
    
    def update(self, stage: int, success: bool, 
               metrics: dict = None):
        """更新阶段结果"""
        idx = self.stages.index(stage)
        if success:
            self.successes[idx] += 1
        else:
            self.failures[idx] += 1
    
    def get_recommendation(self) -> dict:
        """获取推荐灰度策略"""
        expected_rates = self.successes / (self.successes + self.failures)
        return {
            "stages": self.stages,
            "expected_success_rates": expected_rates.tolist(),
            "recommended_strategy": "conservative" if any(r < 0.95 for r in expected_rates) else "aggressive",
        }
```

### 4.2 实际效果

```
初始状态 (无历史数据):
  stages: [5, 10, 20, 40, 100]
  期望成功率: [0.5, 0.5, 0.5, 0.5, 0.5]  (均匀先验)

经过 50 次部署后:
  stages: [5, 10, 20, 40, 100]
  期望成功率: [0.98, 0.96, 0.93, 0.88, 0.82]
  
推荐策略: conservative (因为高阶段成功率 < 0.95)
推荐灰度: 5% → 10% → 20% → 观察 → 40% → 观察 → 100%

经过 500 次部署后:
  stages: [5, 10, 20, 40, 100]
  期望成功率: [0.99, 0.99, 0.98, 0.97, 0.96]

推荐策略: aggressive (所有阶段成功率 > 0.95)
推荐灰度: 10% → 30% → 60% → 100% (更激进)
```

## 5. DBSCAN 告警聚类

### 5.1 算法应用

```python
from sklearn.cluster import DBSCAN
import numpy as np

def cluster_alerts(alerts: list[dict]) -> list[dict]:
    """
    用 DBSCAN 聚类合并相似告警，减少告警风暴
    """
    if len(alerts) < 2:
        return alerts
    
    # 特征: [时间差(归一化), 服务相似度, 指标类型相似度]
    features = []
    for i, alert in enumerate(alerts):
        features.append([
            alert['time_normalized'],     # 时间归一化到 [0,1]
            alert['service_hash'] % 100 / 100,  # 服务哈希
            alert['metric_type_code'],    # 指标类型编码
        ])
    
    X = np.array(features)
    
    # DBSCAN 聚类
    # eps=0.3: 相似度阈值
    # min_samples=2: 至少 2 个告警才成簇
    clustering = DBSCAN(eps=0.3, min_samples=2).fit(X)
    
    # 合并同一簇的告警
    clusters = {}
    for i, label in enumerate(clustering.labels_):
        if label == -1:  # 噪声点，不合并
            clusters[f"single_{i}"] = [alerts[i]]
        else:
            if label not in clusters:
                clusters[label] = []
            clusters[label].append(alerts[i])
    
    # 生成聚类结果
    result = []
    for cluster_id, cluster_alerts in clusters.items():
        if len(cluster_alerts) == 1:
            result.append(cluster_alerts[0])
        else:
            result.append({
                "type": "cluster",
                "alerts": cluster_alerts,
                "count": len(cluster_alerts),
                "representative": cluster_alerts[0],  # 用第一个告警代表
                "time_range": f"{cluster_alerts[0]['time']} ~ {cluster_alerts[-1]['time']}",
                "compression_rate": f"{len(cluster_alerts)} → 1",
            })
    
    return result

# 效果: 200 条原始告警 → 聚类后 15 条，压缩率 92.5%
```
