# XGBoost 特征漂移监控设计

## 1. 背景与目标

在 XGBoost 模型的生产环境中，训练数据与推理数据之间的分布漂移（Data Drift）是导致模型性能下降的主要原因。本设计旨在建立完善的特征漂移监控体系，确保在线/离线数据一致性，及时发现并应对特征分布变化。

**核心目标：**
- 实现特征分布的实时/批量监控
- 建立漂移检测的量化指标体系
- 制定漂移超阈值的自动化应对流程

---

## 2. 漂移检测指标

### 2.1 PSI（Population Stability Index）

PSI 用于衡量两个分布之间的差异程度，是特征漂移检测的核心指标。

**计算公式：**

$$PSI = \sum_{i=1}^{n} (Actual\%_i - Expected\%_i) \times \ln\left(\frac{Actual\%_i}{Expected\%_i}\right)$$

**阈值标准：**

| PSI 值 | 漂移程度 | 处理策略 |
|--------|----------|----------|
| < 0.1  | 无显著漂移 | 持续监控 |
| 0.1-0.25 | 轻度漂移 | 告警通知 |
| > 0.25 | 严重漂移 | 触发重训练 |

### 2.2 KS 检验（Kolmogorov-Smirnov Test）

KS 检验用于判断两组数据是否来自同一分布，适用于连续特征。

**实现要点：**
- 计算两组数据的累积分布函数（CDF）
- 取最大差值作为 KS 统计量
- p-value < 0.05 表示分布显著不同

### 2.3 其他辅助指标

- **均值/标准差变化率**：`(当前值 - 基准值) / 基准值`
- **分位数对比**：P50、P90、P99 的变化
- **类别特征基数变化**：新类别出现频率

### 3.3 监控模式

**实时监控：**
- 适用场景：核心特征、高价值模型
- 检测频率：每 5 分钟
- 延迟要求：< 30 秒

**批量检测：**
- 适用场景：一般特征、离线模型
- 检测频率：每小时/每天
- 资源优化：批量计算降低开销

### 3.4 告警分级

| 级别 | 条件 | 通知方式 | 响应 SLA |
|------|------|----------|----------|
| P0 | PSI > 0.3 且核心特征 | 电话 + 短信 | 15 分钟 |
| P1 | PSI > 0.25 或 多特征漂移 | 短信 + IM | 1 小时 |
| P2 | PSI > 0.1 | IM 通知 | 4 小时 |

## 4. 代码实现

### 4.1 PSI 计算模块

```python
import numpy as np
import pandas as pd
from typing import Tuple, List, Dict
from scipy import stats
import json


def calculate_psi(
    expected: np.ndarray,
    actual: np.ndarray,
    n_bins: int = 10,
    epsilon: float = 1e-6
) -> float:
    """
    计算 PSI（Population Stability Index）
    
    Args:
        expected: 基准分布数据（训练集）
        actual: 实际分布数据（推理集）
        n_bins: 分箱数量
        epsilon: 平滑因子，避免除零
    
    Returns:
        PSI 值
    """
    # 处理离散特征和连续特征
    if len(np.unique(expected)) <= 10:
        # 离散特征：按类别分箱
        categories = np.unique(np.concatenate([expected, actual]))
        bins = len(categories)
    else:
        bins = n_bins
    
    # 计算分位数边界
    percentiles = np.linspace(0, 100, bins + 1)
    breakpoints = np.percentile(np.concatenate([expected, actual]), percentiles)
    
    # 计算各箱的占比
    expected_counts, _ = np.histogram(expected, bins=breakpoints)
    actual_counts, _ = np.histogram(actual, bins=breakpoints)
    
    # 转换为比例并添加平滑因子
    expected_pct = (expected_counts + epsilon) / (len(expected) + bins * epsilon)
    actual_pct = (actual_counts + epsilon) / (len(actual) + bins * epsilon)
    
    # 计算 PSI
    psi = np.sum((actual_pct - expected_pct) * np.log(actual_pct / expected_pct))
    
    return psi


def calculate_ks_test(
    expected: np.ndarray,
    actual: np.ndarray
) -> Tuple[float, float]:
    """
    执行 KS 双样本检验
    
    Args:
        expected: 基准分布数据
        actual: 实际分布数据
    
    Returns:
        (KS 统计量，p-value)
    """
    ks_stat, p_value = stats.ks_2samp(expected, actual)
    return ks_stat, p_value


def feature_drift_report(
    train_df: pd.DataFrame,
    infer_df: pd.DataFrame,
    feature_cols: List[str],
    psi_threshold: float = 0.1,
    ks_threshold: float = 0.05
) -> Dict:
    """
    生成特征漂移检测报告
    
    Args:
        train_df: 训练数据集
        infer_df: 推理数据集
        feature_cols: 特征列名列表
        psi_threshold: PSI 告警阈值
        ks_threshold: KS 检验 p-value 阈值
    
    Returns:
        漂移报告字典
    """
    report = {
        'summary': {
            'total_features': len(feature_cols),
            'drifted_features': 0,
            'high_risk_features': 0
        },
        'features': {}
    }
    
    for col in feature_cols:
        train_data = train_df[col].dropna().values
        infer_data = infer_df[col].dropna().values
        
        psi = calculate_psi(train_data, infer_data)
        ks_stat, p_value = calculate_ks_test(train_data, infer_data)
        
        # 判断漂移状态
        is_drifted = psi > psi_threshold or p_value < ks_threshold
        risk_level = 'high' if psi > 0.25 else ('medium' if psi > 0.1 else 'low')
        
        if is_drifted:
            report['summary']['drifted_features'] += 1
            if risk_level == 'high':
                report['summary']['high_risk_features'] += 1
        
        report['features'][col] = {
            'psi': round(psi, 4),
            'ks_statistic': round(ks_stat, 4),
            'p_value': round(p_value, 4),
            'risk_level': risk_level,
            'is_drifted': is_drifted,
            'train_mean': round(train_data.mean(), 4),
            'infer_mean': round(infer_data.mean(), 4),
            'train_std': round(train_data.std(), 4),
            'infer_std': round(infer_data.std(), 4)
        }
    
    return report
```

### 4.2 特征分布可视化工具

```python
import matplotlib.pyplot as plt
import seaborn as sns
from matplotlib.font_manager import FontProperties


def plot_feature_distribution_comparison(
    train_df: pd.DataFrame,
    infer_df: pd.DataFrame,
    feature_cols: List[str],
    save_path: str = None
) -> None:
    """
    绘制特征分布对比图
    
    Args:
        train_df: 训练数据集
        infer_df: 推理数据集
        feature_cols: 特征列名列表
        save_path: 图片保存路径
    """
    n_features = len(feature_cols)
    cols = 3
    rows = (n_features + cols - 1) // cols
    
    fig, axes = plt.subplots(rows, cols, figsize=(15, 5 * rows))
    axes = axes.flatten()
    
    for idx, col in enumerate(feature_cols):
        ax = axes[idx]
        
        # 绘制训练集分布
        sns.kdeplot(train_df[col].dropna(), label='Train', ax=ax, alpha=0.6)
        
        # 绘制推理集分布
        sns.kdeplot(infer_df[col].dropna(), label='Inference', ax=ax, alpha=0.6)
        
        # 计算并标注 PSI
        psi = calculate_psi(
            train_df[col].dropna().values,
            infer_df[col].dropna().values
        )
        
        # 设置颜色警报
        if psi > 0.25:
            color = 'red'
        elif psi > 0.1:
            color = 'orange'
        else:
            color = 'green'
        
        ax.set_title(f'{col}\nPSI={psi:.4f}', color=color, fontweight='bold')
        ax.legend()
        ax.grid(True, alpha=0.3)
    
    # 隐藏多余子图
    for idx in range(n_features, len(axes)):
        axes[idx].set_visible(False)
    
    plt.tight_layout()
    
    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()
    
    plt.close()


def plot_psi_heatmap(
    drift_history: Dict[str, List[float]],
    feature_cols: List[str],
    save_path: str = None
) -> None:
    """
    绘制 PSI 热力图（展示历史趋势）
    
    Args:
        drift_history: 历史 PSI 数据，格式为 {日期：{特征：PSI 值}}
        feature_cols: 特征列名列表
        save_path: 图片保存路径
    """
    # 构建热力图矩阵
    dates = sorted(drift_history.keys())
    matrix = []
    
    for date in dates:
        row = [drift_history[date].get(col, 0) for col in feature_cols]
        matrix.append(row)
    
    matrix = np.array(matrix)
    
    plt.figure(figsize=(15, 8))
    sns.heatmap(
        matrix,
        xticklabels=feature_cols,
        yticklabels=dates,
        cmap='RdYlGn_r',
        annot=True,
        fmt='.3f',
        vmin=0,
        vmax=0.3
    )
    
    plt.title('Feature Drift PSI Heatmap')
    plt.xlabel('Features')
    plt.ylabel('Date')
    plt.xticks(rotation=45)
    
    if save_path:
        plt.savefig(save_path, dpi=300, bbox_inches='tight')
    else:
        plt.show()
    
    plt.close()
```

### 4.3 Prometheus 监控指标导出

```python
from prometheus_client import Gauge, Counter, start_http_server
import time
import threading


class FeatureDriftMonitor:
    """特征漂移监控指标导出器"""
    
    def __init__(self, port: int = 8000):
        self.port = port
        
        # 定义 Prometheus 指标
        self.psi_gauge = Gauge(
            'feature_psi',
            'Population Stability Index for features',
            ['feature_name', 'model_id']
        )
        
        self.ks_stat_gauge = Gauge(
            'feature_ks_statistic',
            'KS Test statistic for features',
            ['feature_name', 'model_id']
        )
        
        self.drift_alert_counter = Counter(
            'feature_drift_alerts',
            'Count of feature drift alerts',
            ['feature_name', 'model_id', 'alert_level']
        )
        
        self.last_check_gauge = Gauge(
            'feature_drift_last_check_timestamp',
            'Last check timestamp',
            ['model_id']
        )
    
    def update_metrics(self, drift_report: Dict, model_id: str) -> None:
        """
        更新 Prometheus 指标
        
        Args:
            drift_report: 漂移检测报告
            model_id: 模型 ID
        """
        for feature_name, metrics in drift_report['features'].items():
            # 更新 PSI 指标
            self.psi_gauge.labels(
                feature_name=feature_name,
                model_id=model_id
            ).set(metrics['psi'])
            
            # 更新 KS 统计量
            self.ks_stat_gauge.labels(
                feature_name=feature_name,
                model_id=model_id
            ).set(metrics['ks_statistic'])
            
            # 记录告警
            if metrics['is_drifted']:
                level = metrics['risk_level']
                self.drift_alert_counter.labels(
                    feature_name=feature_name,
                    model_id=model_id,
                    alert_level=level
                ).inc()
        
        # 更新最后检查时间
        self.last_check_gauge.labels(model_id=model_id).set(time.time())
    
    def start_server(self) -> None:
        """启动指标 HTTP 服务"""
        start_http_server(self.port)
        print(f"Prometheus metrics server started at port {self.port}")
    
    def run_daemon(self, check_func: callable, interval: int = 300) -> None:
        """
        运行监控守护进程
        
        Args:
            check_func: 漂移检测函数
            interval: 检查间隔（秒）
        """
        def daemon_loop():
            while True:
                try:
                    drift_report = check_func()
                    self.update_metrics(drift_report, model_id='xgboost_model_v1')
                except Exception as e:
                    print(f"Drift check failed: {e}")
                time.sleep(interval)
        
        daemon_thread = threading.Thread(target=daemon_loop, daemon=True)
        daemon_thread.start()
```

### 5.3 特征工程调整机制

```python
class FeatureDriftHandler:
    """特征漂移处理器"""
    
    def __init__(self, config_path: str):
        self.config = self._load_config(config_path)
        self.drift_thresholds = {
            'psi_warning': 0.1,
            'psi_critical': 0.25,
            'ks_pvalue': 0.05
        }
    
    def handle_drift(self, drift_report: Dict) -> Dict:
        """
        处理漂移事件
        
        Args:
            drift_report: 漂移检测报告
        
        Returns:
            处理决策
        """
        decision = {
            'action': 'none',
            'features_to_adjust': [],
            'retrain_required': False,
            'rollback_required': False
        }
        
        high_risk_features = []
        medium_risk_features = []
        
        for feature, metrics in drift_report['features'].items():
            if metrics['risk_level'] == 'high':
                high_risk_features.append(feature)
            elif metrics['risk_level'] == 'medium':
                medium_risk_features.append(feature)
        
        # 决策逻辑
        if len(high_risk_features) >= 3:
            decision['action'] = 'emergency_retrain'
            decision['retrain_required'] = True
            decision['features_to_adjust'] = high_risk_features
        elif len(high_risk_features) == 1:
            # 单特征漂移，尝试特征调整
            decision['action'] = 'feature_adjustment'
            decision['features_to_adjust'] = high_risk_features
        elif len(medium_risk_features) >= 5:
            decision['action'] = 'scheduled_retrain'
            decision['retrain_required'] = True
        
        return decision
    
    def adjust_feature(
        self,
        feature_name: str,
        train_data: np.ndarray,
        infer_data: np.ndarray
    ) -> Dict:
        """
        调整特征处理策略
        
        Args:
            feature_name: 特征名
            train_data: 训练数据
            infer_data: 推理数据
        
        Returns:
            调整建议
        """
        suggestions = {
            'feature': feature_name,
            'current_transformation': 'none',
            'suggested_transformation': 'none',
            'reason': ''
        }
        
        # 分析漂移类型
        train_skew = stats.skew(train_data)
        infer_skew = stats.skew(infer_data)
        
        if abs(infer_skew) > abs(train_skew) * 1.5:
            suggestions['suggested_transformation'] = 'log_transform'
            suggestions['reason'] = '偏度增加，建议对数变换'
        elif infer_data.std() > train_data.std() * 1.5:
            suggestions['suggested_transformation'] = 'standardization'
            suggestions['reason'] = '方差增大，建议标准化'
        elif len(np.unique(infer_data)) > len(np.unique(train_data)) * 1.2:
            suggestions['suggested_transformation'] = 'binning'
            suggestions['reason'] = '类别增多，建议分箱处理'
        
        return suggestions
```
