# 自愈服务详细规格 (Phase 1)

> **日期**: 2026-07-02
> **状态**: 已验证
> **能力域**: 6. 自愈与弹性
> **目标成熟度**: L2 → L3
> **关键交付**: 自愈策略、风暴抑制、K8s 集成、知识库

## 一、功能描述

### 1.1 现状评估 (L2)

Orion 当前已实现：
- 自愈策略引擎（SelfHealingService + SelfHealingPolicy）
- 故障检测（基于监控指标的异常检测）
- 自愈动作执行（重启/扩缩容/回滚）
- 风暴抑制（EventStormSuppressionService）
- SSE 实时推送（自愈事件通知）
- 自愈历史记录（PostgreSQL 持久化）

**不足**：
- 多租户隔离缺失（自愈策略/历史数据无 tenant_id 过滤）
- 知识库未集成到主流程（自愈建议未利用知识库）
- 前端页面需完善（缺少策略配置页面）
- 死代码需清理（部分实验性代码未移除）
- K8s 集成需确认（自愈动作是否真实对接 K8s API）

### 1.2 Phase 1 目标 (L3)

| 功能模块 | 描述 | 验收等级 |
|----------|------|:--------:|
| 多租户隔离 | 自愈策略/历史/事件按租户隔离 | L3 |
| 知识库集成 | 自愈建议引用知识库文章 | L3 |
| 前端完善 | 策略配置页面、历史展示 | L3 |
| 代码清理 | 移除死代码，优化结构 | L3 |

## 二、验收标准

| S1 | 自愈策略按 tenant_id 隔离 | API 测试 |

### 2.2 知识库集成

| # | 标准 | 验证方式 |
|---|------|----------|
| K1 | 自愈建议可关联知识库文章 | API 测试 |

| K3 | 知识库匹配结果展示在自愈事件详情中 | 前端验证 |

### 2.3 前端页面

| F1 | 自愈策略列表：展示/启禁/编辑 | 前端验证 |
| F2 | 自愈策略编辑：条件配置 + 动作配置 | 前端验证 |
| F3 | 自愈历史：时间线展示、状态筛选 | 前端验证 |
| F4 | 自愈详情：触发条件、执行动作、结果 | 前端验证 |

## 三、API 设计

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/self-healing/policies` | 获取自愈策略列表 |
| POST | `/api/v1/self-healing/policies` | 创建自愈策略 |
| PUT | `/api/v1/self-healing/policies/:id` | 更新自愈策略 |
| DELETE | `/api/v1/self-healing/policies/:id` | 删除自愈策略 |
| GET | `/api/v1/self-healing/history` | 获取自愈历史 |
| GET | `/api/v1/self-healing/history/:id` | 获取自愈详情 |
