# 配置管理详细规格 (Phase 1)

> **日期**: 2026-07-02
> **状态**: 已验证
> **能力域**: 10. 配置管理
> **目标成熟度**: L2 → L3
> **关键交付**: 配置 CRUD、版本快照、GitOps 集成、校验 Schema

## 一、功能描述

### 1.1 现状评估 (L2)

Orion 当前已实现：
- 配置管理 CRUD（ConfigService + ConfigRepository + config-routes）
- 环境管理（EnvironmentService，开发/测试/预发/生产）
- 配置分组（按应用/环境/模块组织）
- GitOps 配置同步基础（GitOps 适配器）
- 配置漂移检测基础（DriftDetectionService）

**不足**：
- 版本快照管理缺失（无配置变更历史/回退）
- 配置校验 Schema 缺失（无法定义配置字段类型/约束）
- Webhook/通知缺失（配置变更无通知）
- 配置模板缺失（无预定义配置模板）
- 灰度发布配置不支持（无法按比例发布配置变更）

### 1.2 Phase 1 目标 (L3)

| 功能模块 | 描述 | 验收等级 |
|----------|------|:--------:|
| 版本快照 | 配置变更历史、版本对比、回退 | L3 |
| 校验 Schema | JSON Schema 定义、字段类型/约束校验 | L3 |
| Webhook 通知 | 配置变更自动通知 | L3 |
| 配置模板 | 预置模板、自定义模板 | L3 |

## 二、验收标准

### 2.1 版本快照

| # | 标准 | 验证方式 |
|---|------|----------|
| V1 | 每次配置更新自动创建版本快照 | API 测试 |
| V2 | 支持版本对比（diff 格式显示差异） | API 测试 |
| V3 | 支持回退到任意历史版本 | API 测试 |
| V4 | 版本历史按时间倒序，含操作人/变更说明 | 前端验证 |

### 2.2 校验 Schema

| # | 标准 | 验证方式 |
|---|------|----------|
| S1 | 支持为配置定义 JSON Schema（类型/必填/枚举/正则） | API 测试 |
| S2 | 配置更新时自动校验 Schema | 集成测试 |
| S3 | 校验失败时返回具体错误信息（字段/约束/期望值） | API 测试 |
| S4 | 预置 5+ 公共 Schema（数据库连接/Redis/日志/端口/URL） | 单元测试 |

### 2.3 Webhook 通知

| # | 标准 | 验证方式 |
|---|------|----------|
| W1 | 配置变更时触发 Webhook（含变更内容/操作人/时间） | 集成测试 |
| W2 | 支持配置通知目标（邮件/钉钉/企微） | 集成测试 |
| W3 | 敏感配置变更（密码/密钥）发送高优先级通知 | 集成测试 |

### 2.4 配置模板

| # | 标准 | 验证方式 |
|---|------|----------|
| T1 | 预置 5+ 模板（Nginx/Redis/PostgreSQL/Node.js/Java） | 前端验证 |
| T2 | 从模板创建配置时自动填充默认值 | 前端 + API 测试 |
| T3 | 用户可自定义配置模板 | API 测试 |

## 三、API 设计

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/config` | 配置列表 |
| POST | `/api/v1/config` | 创建配置 |
| PUT | `/api/v1/config/:id` | 更新配置 |
| GET | `/api/v1/config/:id/versions` | 版本历史 |
| GET | `/api/v1/config/:id/versions/:vid` | 版本详情 |
| POST | `/api/v1/config/:id/rollback/:vid` | 回退到指定版本 |
| GET | `/api/v1/config/schemas` | Schema 列表 |
| POST | `/api/v1/config/schemas` | 创建 Schema |
| GET | `/api/v1/config/templates` | 模板列表 |
