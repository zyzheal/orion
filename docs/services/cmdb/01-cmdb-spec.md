# CMDB 配置管理详细规格 (Phase 1)

> **日期**: 2026-07-02
> **状态**: 已验证
> **能力域**: 5. 配置管理数据库
> **目标成熟度**: L2 → L3
> **关键交付**: CI 管理、拓扑分析、关系类型、批量操作

## 一、功能描述

### 1.1 现状评估 (L2)

Orion 当前已实现：
- CI 类型管理（ci-type-routes + ci-type 模型）
- CI 实例管理（CRUD 操作，PostgreSQL 持久化）
- CI 关系管理（关系类型定义 + 实例关联）
- 拓扑分析基础（CMDB 拓扑服务）
- 前端页面（CMDB 管理页面）
- 导入/导出框架（CSV 导出基础实现）

**不足**：
- 批量操作 API 缺失（无批量创建/更新/删除）
- CI 导入/导出不完整（仅 CSV 导出，无导入功能）
- 拓扑性能优化不足（大数据量下页面卡顿）
- 内存模式租户隔离缺失（降级时无 tenant_id 过滤）
- 关系类型管理 API 缺失（无法自定义关系类型）
- CI 归档/恢复缺失（无软删除+恢复机制）

### 1.2 Phase 1 目标 (L3)

| 功能模块 | 描述 | 验收等级 |
|----------|------|:--------:|
| 批量操作 | 批量创建/更新/删除 CI 实例 | L3 |
| 导入导出 | CSV/JSON 导入导出、字段映射 | L3 |
| 拓扑优化 | 懒加载、虚拟滚动、缓存策略 | L3 |
| 租户隔离 | 降级模式下的 tenant_id 过滤 | L3 |
| 关系类型 | 自定义关系类型管理 | L3 |

## 二、验收标准

### 2.1 批量操作

| # | 标准 | 验证方式 |
|---|------|----------|
| B1 | 支持批量创建 CI（最多 100 条/次） | API 测试 |
| B2 | 支持批量更新 CI（按 ID 列表，可指定字段） | API 测试 |
| B3 | 支持批量删除 CI（软删除，可恢复） | API 测试 |
| B4 | 批量操作结果返回成功/失败明细 | API 测试 |
| B5 | 批量操作在事务中执行，部分失败自动回滚 | 集成测试 |

### 2.2 导入导出

| # | 标准 | 验证方式 |
|---|------|----------|
| I1 | 支持 CSV 导入（自动检测字段映射） | API 测试 |
| I2 | 支持 JSON 导入（兼容 CMDB 数据模型） | API 测试 |
| I3 | 导入时数据校验（必填字段、类型匹配） | 单元测试 |
| I4 | 导入结果报告（成功 N 条，失败 M 条，失败原因） | API 测试 |
| I5 | 导出支持 CSV 和 JSON 格式 | API 测试 |

### 2.3 拓扑优化

| # | 标准 | 验证方式 |
|---|------|----------|
| T1 | 拓扑图加载使用懒加载（按需加载节点） | 前端验证 |
| T2 | 拓扑图支持虚拟滚动（1000+ 节点不卡顿） | 前端验证 |
| T3 | 拓扑数据缓存（Redis，5 分钟 TTL） | 集成测试 |
| T4 | 拓扑图支持缩放/拖拽/节点搜索 | 前端验证 |

### 2.4 关系类型

| # | 标准 | 验证方式 |
|---|------|----------|
| R1 | 支持自定义关系类型（如"运行在""依赖""连接"） | API 测试 |
| R2 | 关系类型可配置源/目标 CI 类型约束 | API 测试 |
| R3 | 关系类型可配置 Cardinality（一对一/一对多/多对多） | API 测试 |

## 三、API 设计

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/cmdb/batch` | 批量操作 CI |
| POST | `/api/v1/cmdb/import` | 导入 CI |
| GET | `/api/v1/cmdb/export` | 导出 CI |
| GET | `/api/v1/cmdb/relation-types` | 获取关系类型列表 |
| POST | `/api/v1/cmdb/relation-types` | 创建关系类型 |
| PUT | `/api/v1/cmdb/relation-types/:id` | 更新关系类型 |
