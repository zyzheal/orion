## 风险提示

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|---------|
| Phase 2 (as any/Design Token) | 类型定义错误导致编译失败 | TypeScript 编译不通过则 CI 自动拦截，不合并 |
| Phase 3 (后端权限修复) | 权限中间件可能阻断正常请求 | 先在预发环境验证，确认不影响现有功能后再上生产 |
| Phase 3.5 (已有模块增强) | 前后端联调可能暴露接口不兼容 | API 路径变更通过 Gateway 转发兼容旧路径 |
| Phase 4 (新模块开发) | 新功能影响现有系统稳定性 | 新模块使用独立路由前缀，不修改已有模块代码 |
| 49+ 人月估算偏乐观 | 中 | 高 | 每阶段预留 20% 缓冲时间，Phase 4 新模块分批验收 |
