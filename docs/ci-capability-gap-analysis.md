## 五、关键差距分析

### 5.1 最大短板：安全与合规（差距 6 项）

国内大厂均将安全能力作为核心竞争力：
- 云效：SAST + SCA + RASS 运行时安全 + 合规报告
- CODING：15+ 语言代码扫描 + 等保2.0/GDPR 预检
- CodeArts：500+ 规则 + SBOM + 三级合规

Orion 目前仅有 Secret 加密和质量门禁，**完全没有 SAST/SCA 能力**，这是企业用户的核心诉求。

### 5.2 第二大短板：集成生态（差距 8 项）

国内大厂 CI 都不是独立产品，而是生态的一部分：
- 云效 → 阿里云全家桶（ECS/ACK/ACR/SLS/ARMS/AHAS）
- CODING → 腾讯全家桶（TKE/SCF/TCR/CLS）+ 项目管理闭环
- CodeArts → 华为全家桶（CCE/FunctionGraph/OBS/LTS/AOM）+ 全套 DevOps
- Gitee Go → Gitee 代码托管 + PR + Issue + Wiki 全打通

Orion 目前是**独立系统**，缺少与 SCM 的深度联动（PR 触发/回写）、通知系统、IDE 插件等。

### 5.3 第三大短板：企业治理能力（差距 4 项）

多租户、审计日志、配额管理是企业级产品的标配，Orion 当前完全没有。

## 七、结论

Orion 在**核心流水线引擎**（DAG 调度、并行执行、Matrix 展开、子流水线）方面已**与国内大厂持平甚至领先**，但在以下三个维度存在显著差距：

1. **安全与合规**（最短板）：缺少 SAST/SCA/合规报告，企业用户无法通过安全审计
2. **集成生态**（第二短板）：缺少 PR/MR 联动、通知系统、IDE 插件，用户体验不如云原生平台
3. **企业治理**（第三短板）：缺少多租户/审计/配额，无法支撑多团队协作

建议优先补齐 **Phase A** 的 5 项能力，即可将覆盖率从 57.7% 提升至约 **75%**，接近云效 94% 的核心差距缩小到可接受范围。
