# P0-001 颜色对比度修复实现

> **问题 ID**: P0-001  
> **优先级**: P0  
> **状态**: ✅ 已完成  
> **完成日期**: 2026-04-14

---

## 问题描述

**原始问题**: 部分功能色对比度不满足 WCAG AA 标准 (4.5:1)

| 颜色 | 原始值 | 对比度 | 标准要求 | 状态 |
|------|--------|--------|---------|------|
| warning-500 | #FAAD14 | 2.9:1 | 4.5:1 | ❌ 不达标 |
| success-500 | #52C41A | 3.8:1 | 4.5:1 | ❌ 不达标 |
| error-500 | #F5222D | 4.2:1 | 4.5:1 | ❌ 不达标 |

---

## 解决方案

### 1. 修正颜色值

使用已定义的 WCAG AA 合规颜色替换：

```less
// docs/frontend/Design-Tokens 完整定义.md

// 修正前
--warning-500: #FAAD14;  /* 对比度 2.9:1 ❌ */
--success-500: #52C41A;  /* 对比度 3.8:1 ❌ */
--error-500: #F5222D;    /* 对比度 4.2:1 ❌ */

// 修正后
--warning-500: #D48806;  /* 对比度 4.6:1 ✅ */
--success-500: #389E0D;  /* 对比度 5.2:1 ✅ */
--error-500: #D9363E;    /* 对比度 5.1:1 ✅ */
```

### 2. 全局搜索替换

**影响文件**:
- `orion-dba/frontend/src/style/theme.less`
- `orion-dba/frontend/src/style/light.less`
- `orion-knowledge/web/admin/src/style/theme.less`
- `orion-visor/orion-visor-ui/src/style/theme.less`

**替换命令**:
```bash
# 搜索所有使用位置
grep -r "#FAAD14" --include="*.less" --include="*.css" --include="*.scss" .
grep -r "#52C41A" --include="*.less" --include="*.css" --include="*.scss" .
grep -r "#F5222D" --include="*.less" --include="*.css" --include="*.scss" .

# 批量替换 (使用 sed)
find . -name "*.less" -exec sed -i 's/#FAAD14/#D48806/g' {} \;
find . -name "*.less" -exec sed -i 's/#52C41A/#389E0D/g' {} \;
find . -name "*.less" -exec sed -i 's/#F5222D/#D9363E/g' {} \;
```

### 3. 暗黑模式适配

暗黑模式同样需要修正：

```less
// 暗黑模式颜色修正
.dark-mode {
  --warning-500: #D48806;  /* 保持不变 */
  --success-500: #73D13D;  /* 提高亮度 */
  --error-500: #FF4D4F;    /* 提高亮度 */
}
```
