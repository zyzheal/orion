## 2. 缺失功能清单

### P0 (紧急)
- **数据持久化**: 设计文档 → `数据库选型设计.md` ADR-005 | 影响: 30+ 服务使用 Map() 模拟，重启后数据丢失
- **RLS 行级安全策略**: 设计文档 → `多租户隔离设计.md` | 影响: 多租户数据未隔离
- **ClickHouse 集成**: 设计文档 → ADR-006 | 影响: 无法进行大数据量分析

### P1 (重要)
- **DB 连接池**: 设计文档 → `数据库连接池设计.md` | 影响: 无连接复用和池化管理
- **迁移幂等性**: 部分迁移文件非幂等 | 影响: 重复执行可能失败

### P2 (完善)
- **Neo4j 依赖图**: 设计文档 → `dependency-tracking-design.md` | 影响: 无依赖关系图谱

## 4. 关键发现

1. **Map() 模拟存储是最大问题**: 30+ 服务使用 `new Map()` 作为数据存储，是系统级技术债务
2. **迁移文件编号混乱**: 存在两个 010（create_approvals 和 create_artifact_registry）和两个 011
3. **ClickHouse/Neo4j 完全缺失**: ADR-006 和依赖追踪设计完整但零代码
4. **审计链有持久化意图**: ImmutableAuditStorage 设计意图明确，但未落地
