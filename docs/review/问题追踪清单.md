## 问题详细实现记录

### P0-001: 颜色对比度不达标

**问题描述**: warning-500 对比度 2.9:1，不满足 WCAG AA 4.5:1 要求

**解决方案**:
1. 修正颜色值为 --warning-500: #D48806
2. 全局搜索替换所有使用位置
3. 验证对比度达标

**实现文件**:
- `docs/frontend/Design-Tokens 完整定义.md`
- `orion-dba/frontend/src/style/theme.less`
- `orion-knowledge/web/admin/src/style/theme.less`

**验收标准**:
- [ ] 所有功能色对比度 ≥ 4.5:1
- [ ] 通过 WCAG AA 验证工具检测
- [ ] 暗黑模式对比度同样达标

**状态**: ⏳ 待开始

---

### P0-002: 动态内容无屏幕阅读器通知

**问题描述**: WebSocket 推送等动态内容更新时，屏幕阅读器用户无法感知

**解决方案**:
1. 创建 `aria-live` 区域组件
2. 封装 `notifyScreenReader()` 工具函数
3. 在所有动态更新处调用通知

**实现文件**:
- `orion-dba/frontend/src/components/ScreenReaderAnnouncer.tsx`
- `orion-dba/frontend/src/utils/accessibility.ts`

**验收标准**:
- [ ] 所有 WebSocket 消息推送触发通知
- [ ] 流水线状态更新触发通知
- [ ] 审批请求触发通知
- [ ] 通过屏幕阅读器测试

**状态**: ⏳ 待开始

---

### P0-003: 图表缺少文本替代描述

**问题描述**: 效能看板等图表无 alt 文本，视障用户无法理解数据

**解决方案**:
1. 为所有图表组件添加 `aria-label` 和 `aria-describedby`
2. 生成图表数据长描述
3. 提供数据表格替代视图

**实现文件**:
- `orion-dba/frontend/src/components/Chart/ChartAccessibility.tsx`
- `orion-dba/frontend/src/components/Chart/DataTable.tsx`

**验收标准**:
- [ ] 所有图表有长描述 (≥100 字符)
- [ ] 提供数据表格下载
- [ ] 通过屏幕阅读器测试

**状态**: ⏳ 待开始
