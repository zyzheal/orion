# Orion Platform - 子系统导航与 Dashboard 设计方案

## 设计概述

本次设计包含两个核心部分：
1. **子系统启动器** - 左上角动态效果入口
2. **工作看板 Dashboard** - 展示待处理事项和系统状态

---

## 一、子系统启动器设计

### 1.1 位置与外观
```
┌────────────────────────────────────────────────┐
│ [≡] 🟣 子系统    [🌙]  [👤 用户]              │
│  ↑                                            │
│  九宫格图标，带脉冲动画效果                      │
└────────────────────────────────────────────────┘
```

### 1.2 交互效果
- **默认状态**: 紫色渐变背景，带呼吸脉冲动画
- **Hover 状态**: 放大 1.05 倍，阴影增强
- **Click**: 弹出子系统菜单

### 1.3 弹出菜单设计
```
┌─────────────────────────────────────────┐
│  子系统应用                              │
│  点击图标进入相应的子系统                │
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ 🗄️  数据库管理           [3]       │ │
│ │    SQL 执行·数据建模                 │ │
│ │    ← 滑入动画                        │ │
│ ├─────────────────────────────────────┤ │
│ │ 📚  知识库                            │ │
│ │    文档管理·经验分享                 │ │
│ ├─────────────────────────────────────┤ │
│ │ 📊  监控中心           [1]           │ │
│ │    系统监控·告警管理                 │ │
│ └─────────────────────────────────────┘ │
├─────────────────────────────────────────┤
│  按 Esc 关闭                             │
└─────────────────────────────────────────┘
```

### 1.4 动态效果
- **卡片滑入**: 点击后向右滑出 8px
- **光泽扫过**: Hover 时光泽从左到右扫过
- **阴影增强**: Hover 时彩色阴影浮现
- **脉冲动画**: 持续呼吸效果

## 二、Dashboard 工作看板设计

### 2.1 整体布局
```
┌──────────────────────────────────────────────────────────────┐
│  统计卡片区 (4 个)                                             │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                        │
│ │Pipeline│ │运行中 │ │ 成功  │ │待处理 │                        │
│ └──────┘ └──────┘ └──────┘ └──────┘                        │
├──────────────────────────────────────────────────────────────┤
│                         │                                    │
│   待处理任务            │     系统健康状态                   │
│   ┌─────────────────┐   │   ┌─────────────────────┐         │
│   │ 任务列表表格     │   │   │ API Gateway  ✅     │         │
│   │ - F206 联调测试   │   │   │ Platform Svc ✅     │         │
│   │ - 修复超时问题   │   │   │ Database    ✅      │         │
│   │ - 更新 API 文档   │   │   │ Redis       ✅      │         │
│   └─────────────────┘   │   │ Event Bus   ⚠️      │         │
│                         │   └─────────────────────┘         │
│   最近 Pipeline 执行     │                                    │
│   ┌─────────────────┐   │     快速操作                       │
│   │ Pipeline 列表    │   │   ┌────┐ ┌────┐                 │
│   │ - frontend-deploy│   │   │创建│ │查看│                 │
│   │ - api-build     │   │   │Pipeline│ │日志│              │
│   └─────────────────┘   │   └────┘ └────┘                 │
│                         │                                    │
│                         │     系统提醒                       │
│                         │   ⚠️ Event Bus 延迟高               │
│                         │   ✅ 子系统正常                    │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 统计卡片
| 卡片 | 内容 | 颜色 | 图标 |
|------|------|------|------|
| Pipeline 总数 | 24 + 完成率进度条 | 蓝色 | Thunderbolt |
| 运行中 | 3 个任务执行中 | 橙色 | ClockCircle |
| 成功 | 156 + 成功率 95% | 绿色 | CheckCircle |
| 待处理任务 | 5 + 进行中数量 | 红色 | Warning |

### 2.3 待处理任务列表
- 任务名称 + 优先级标签 (高/中/低)
- 状态徽章 (进行中/待开始/已完成)
- 负责人
- 截止时间
- 处理按钮

### 2.4 Pipeline 执行列表
- Pipeline 名称
- 状态指示器
- 执行耗时
- 触发人
- 时间
- 操作 (查看/重试)

### 2.5 系统健康状态
- 服务名称 + 状态徽章
- 响应延迟
- 可用性百分比

### 2.6 快速操作
| 操作 | 图标 | 颜色 |
|------|------|------|
| 创建 Pipeline | Rocket | 蓝色 |
| 查看日志 | Code | 绿色 |
| 运行任务 | PlayCircle | 紫色 |
| 历史记录 | History | 橙色 |

## 三、技术实现

### 3.1 组件结构
```
src/
├── components/
│   ├── Layout/
│   │   └── index.tsx          # 添加 SubAppLauncher
│   └── SubAppLauncher/
│       └── index.tsx          # 子系统启动器组件
└── pages/
    ├── DashboardNew/
    │   └── index.tsx          # 新 Dashboard
    └── SubApps/
        └── index.tsx          # 子系统导航页
```

### 3.2 动画实现
```css
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 0; }
  50% { transform: scale(1.5); opacity: 0.5; }
}

/* 光泽扫过动画 */
background: linear-gradient(90deg, transparent, rgba(255,255,255,0.3), transparent);
transform: translateX(-100%);
transition: transform 0.5s ease;
```

### 3.3 状态管理
- 使用 Zustand 存储全局状态
- 用户认证状态共享
- 主题配置同步
- EventBus 通信

## 四、使用方式

### 4.1 访问子系统
1. 点击左上角 🟣 九宫格图标
2. 从弹出菜单选择子系统
3. 或从侧边栏"子系统"菜单进入

### 4.2 Dashboard 功能
- 查看待处理任务并处理
- 监控 Pipeline 执行状态
- 查看系统健康状态
- 使用快速操作入口
