# 子应用接入规范

**版本**: 1.0  
**创建日期**: 2026-04-11  
**适用范围**: orion-dba、orion-knowledge、orion-visor 及未来所有子应用

---

## 一、概述

本规范定义了在 wujie 微前端架构下，子应用接入 Orion 主应用的标准方式。

### 核心要求

1. **双模式支持**: 子应用必须支持独立运行和微前端嵌入两种模式
2. **生命周期导出**: 必须导出 wujie 要求的生命周期函数
3. **Props 接收**: 必须能接收主应用注入的全局状态
4. **样式隔离**: 必须使用样式隔离方案
5. **路由规范**: 必须遵循统一的路由前缀规范

## 二、入口文件规范

### 2.1 生命周期导出

所有子应用必须在入口文件中导出 wujie 生命周期函数：

```typescript
// src/main.ts

import { createApp } from 'vue' // 或 import React from 'react'
import App from './App.vue'

let instance: ReturnType<typeof createApp> | null = null

/**
 * 渲染函数
 * @param props 主应用注入的 props
 */
function render(props: Record<string, unknown> = {}) {
  const { container } = props
  
  instance = createApp(App)
  
  // 使用传入的容器，否则挂载到默认容器
  if (container) {
    instance.mount(container.querySelector('#app') || container)
  } else {
    instance.mount('#app')
  }
}

/**
 * 子应用启动（可选）
 */
export async function bootstrap() {
  console.log('[SubApp] bootstrap')
}

/**
 * 子应用挂载（必需）
 */
export async function mount(props: Record<string, unknown>) {
  console.log('[SubApp] mount', props)
  // 存储主应用注入的全局状态
  window.__POWERED_BY_WUJIE__ = true
  render(props)
}

/**
 * 子应用卸载（必需）
 */
export async function unmount() {
  console.log('[SubApp] unmount')
  if (instance) {
    instance.unmount()
    instance._container.innerHTML = ''
    instance = null
  }
  window.__POWERED_BY_WUJIE__ = false
}

// 独立运行时直接挂载
if (!window.__POWERED_BY_WUJIE__) {
  render()
}
```

### 2.2 独立运行检测

```typescript
// 检测是否在 wujie 沙箱中运行
export const isWujieSubApp = (): boolean => {
  return !!(window as unknown as { __POWERED_BY_WUJIE__: boolean }).__POWERED_BY_WUJIE__
}

// 检测函数也可用于条件逻辑
if (isWujieSubApp()) {
  // 微前端模式下的逻辑
} else {
  // 独立运行模式下的逻辑
}
```

## 三、Props 接收规范

### 3.1 标准 Props 接口

子应用应能接收以下标准 props：

```typescript
interface OrionSubAppProps {
  /** 主应用注入的全局状态 */
  $orion: {
    /** 用户信息 */
    user: {
      id: string
      name: string
      email: string
      roles: string[]
      tenantId: string
    } | null
    
    /** 认证 Token */
    token: string | null
    
    /** 当前主题 */
    theme: 'light' | 'dark'
    
    /** 侧边栏收起状态 */
    sidebarCollapsed: boolean
    
    /** 面包屑导航 */
    breadcrumbs: Array<{ title: string; path?: string }>
    
    /** 权限列表 */
    permissions: string[]
    
    /** 获取 API 基础路径 */
    getApiBase: () => string
    
    /** 事件总线 */
    eventBus: {
      emit: (event: string, data: unknown) => void
      on: (event: string, callback: (data: unknown) => void) => void
      off: (event: string, callback: (data: unknown) => void) => void
    }
  }
}
```

### 3.2 Props 使用示例

```typescript
// 在组件中接收并使用 props
export default {
  name: 'SubAppComponent',
  props: {
    $orion: {
      type: Object,
      required: true
    }
  },
  setup(props) {
    // 访问用户信息
    const userInfo = props.$orion.user
    
    // 访问 Token
    const token = props.$orion.token
    
    // 使用事件总线
    const emitEvent = () => {
      props.$orion.eventBus.emit('custom-event', { data: 'value' })
    }
    
    return {
      userInfo,
      token,
      emitEvent
    }
  }
}
```

### 3.3 全局状态访问

```typescript
// 创建全局状态 store
import { reactive } from 'vue'

export const globalState = reactive({
  user: null,
  token: null,
  theme: 'light',
  permissions: []
})

// 在 mount 时更新状态
export async function mount(props: Record<string, unknown>) {
  const orionState = (props as any).$orion
  
  if (orionState) {
    globalState.user = orionState.user
    globalState.token = orionState.token
    globalState.theme = orionState.theme
    globalState.permissions = orionState.permissions
  }
  
  render(props)
}
```

## 四、构建配置规范

### 4.1 Vite 配置 (Vue 3)

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import path from 'path'

const isDev = process.env.NODE_ENV === 'development'
const isMicroFrontend = process.env.MODE === 'micro-frontend'

export default defineConfig({
  plugins: [vue()],
  
  base: isDev ? '/' : '/orion-dba/',
  
  server: {
    port: isMicroFrontend ? 3001 : 5173,
    cors: true,
    headers: {
      'Access-Control-Allow-Origin': '*'
    }
  },
  
  build: {
    outDir: isMicroFrontend ? 'dist-mf' : 'dist',
    
    rollupOptions: {
      // 微前端模式需要输出 UMD 格式
      ...(isMicroFrontend && {
        output: {
          format: 'umd',
          name: 'OrionDbaApp',
          entry: 'src/main.ts'
        }
      }),
      
      // 外部依赖（避免打包重复库）
      external: isMicroFrontend ? ['vue', 'vue-router', 'ant-design-vue'] : []
    },
    
    // 微前端模式不压缩文件名，便于调试
    minify: !isMicroFrontend,
    sourcemap: isMicroFrontend
  },
  
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src')
    }
  }
})
```

## 五、样式隔离规范

### 5.1 样式前缀规范

所有自定义样式必须添加应用级前缀：

```less
// orion-dba: 使用 .dba- 前缀
.dba-container {
  .dba-header {
    /* 样式 */
  }
  
  .dba-content {
    /* 样式 */
  }
}

// orion-knowledge: 使用 .knowledge- 前缀
.knowledge-container {
  /* 样式 */
}

// orion-visor: 使用 .visor- 前缀
.visor-container {
  /* 样式 */
}
```

### 5.2 CSS Modules (可选)

```typescript
// 使用 CSS Modules 进行更严格的隔离
// Button.module.css
.button {
  background: blue;
}

// 在组件中使用
import styles from './Button.module.css'

export default {
  render() {
    return <button class={styles.button}>按钮</button>
  }
}
```

### 5.3 z-index 管理

子应用的 z-index 应限制在 0-1000 范围内，避免与主应用冲突：

```css
/* 正确 */
.modal { z-index: 900; }
.dropdown { z-index: 800; }

/* 错误 - 可能覆盖主应用 */
.modal { z-index: 9999; }
```

## 六、路由规范

### 6.1 路由前缀

各子应用必须使用指定的路由前缀：

| 子应用 | 路由前缀 | 示例 |
|--------|---------|------|
| orion-dba | `/dba` | `/dba/instances` |
| orion-knowledge | `/knowledge` | `/knowledge/articles` |
| orion-visor | `/visor` | `/visor/dashboard` |

### 6.2 路由配置示例 (Vue Router)

```typescript
// router/index.ts
import { createRouter, createWebHistory } from 'vue-router'

const baseRoute = '/dba' // 根据子应用修改

const router = createRouter({
  history: createWebHistory(baseRoute),
  routes: [
    {
      path: '/',
      redirect: `${baseRoute}/home`
    },
    {
      path: '/home',
      component: () => import('@/views/Home.vue')
    },
    {
      path: '/instances',
      component: () => import('@/views/Instances.vue')
    }
  ]
})

export default router
```

### 6.3 路由跳转

```typescript
// 子应用内部跳转使用相对路径
router.push('/instances') // 会自动加上前缀 /dba/instances

// 跳转到其他子应用需要通过主应用
props.$orion.eventBus.emit('navigate', { path: '/knowledge/articles' })
```

## 七、API 调用规范

### 7.1 API 客户端封装

```typescript
// api/client.ts
import axios from 'axios'

const getApiBase = () => {
  // 优先使用主应用注入的方法，否则使用环境变量
  return (window as any).$orion?.getApiBase?.() || import.meta.env.VITE_API_BASE_URL
}

const client = axios.create({
  baseURL: getApiBase(),
  timeout: 30000
})

// 请求拦截器 - 自动添加 Token
client.interceptors.request.use((config) => {
  const token = (window as any).$orion?.token || localStorage.getItem('token')
  if (token) {
    config.headers['X-Orion-Token'] = token
  }
  return config
})

// 响应拦截器 - 处理 401/403
client.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      // 重定向到登录页
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)

export default client
```

## 八、通信规范

### 8.1 子应用 → 主应用

通过事件总线发送：

```typescript
// 通知主应用更新面包屑
props.$orion.eventBus.emit('breadcrumbs:update', [
  { title: '首页', path: '/' },
  { title: '实例管理', path: '/dba/instances' }
])

// 请求主应用导航
props.$orion.eventBus.emit('navigate', { path: '/knowledge/articles' })
```

### 8.2 主应用 → 子应用

通过 props 或事件：

```typescript
// 主应用发送事件
eventBus.emit('theme:change', { theme: 'dark' })

// 子应用监听
props.$orion.eventBus.on('theme:change', (data) => {
  console.log('主题变更', data)
})
```

## 附录

### A. 常见问题

**Q: 样式被主应用覆盖怎么办？**

A: 使用更深的前缀选择器或 CSS Modules，确保选择器优先级。

**Q: 子应用路由 404？**

A: 检查路由 base 配置是否正确，确保与主应用路由前缀一致。

**Q: Token 失效怎么办？**

A: 子应用通过 props.$orion.token 获取最新 Token，主应用负责刷新。
