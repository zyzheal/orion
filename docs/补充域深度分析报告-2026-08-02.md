### 3.2 ⚠️ 模板复制问题（重大发现）

**mlops、inspection、metadata 三个模块的 handler.go 是同一模板的复制粘贴**：

```
mlops/handler/handler.go:      28,157 字节
inspection/handler/handler.go: 28,537 字节
metadata/handler/handler.go:   26,580 字节
```

三者共享 **18 个完全相同的通用方法名**：
`List`/`Get`/`Create`/`Update`/`Delete`/`RunInspection`/`GetResults`/`UpdateStatus`/`ListTemplates`/`GetStats`/`RunPipeline`/`GetStatus`/`Pause`/`Resume`/`GetLogs`/`ListSchemas`/`GetLineage`/`GetConfig`/`UpdateConfig`

**仅 import 路径 + route 前缀 + 权限名不同**。

**mlops 的真实 MLOps 方法仅 7 个**：
`Train`/`Evaluate`/`Deploy`/`Rollback`/`GetMetrics`/`ListExperiments`/`ListArtifacts`

其余 18 个方法为"巡检元数据/Schema 管理/血缘追踪"等与 MLOps 语义无关的通用模板方法。

**inspection 和 metadata 同理**：handler 声称 62 个方法，实际业务方法仅 ~14 个，其余 48 个为模板复制。
