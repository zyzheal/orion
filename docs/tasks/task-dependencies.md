## 依赖类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| 硬依赖 | 必须在前置任务完成后才能开始 | 数据库设计 → 表创建 |
| 软依赖 | 建议等待前置任务，但可并行 | API 定义 → Mock 实现 |
| 无依赖 | 可独立并行开发 | 独立工具函数 |

## 风险点

| 风险 | 影响任务 | 缓解措施 |
|------|----------|----------|
| wujie 框架学习成本 | TASK-902, TASK-1101 | 提前安排技术培训，参考腾讯官方文档 |
| 外部系统技术栈复杂 | TASK-1107~1109 | 详细调研，制定分步迁移方案 |
| 样式隔离不彻底 | TASK-1103 | 采用 CSS Modules + 前缀规范双重隔离 |
| 子应用通信问题 | TASK-1104 | 制定统一通信协议，提供 SDK 封装 |
| Vue→React 迁移成本 | TASK-1107, TASK-1109 | 评估 wujie 直接接入 Vue 子应用可行性 |
| 联调进度延期 | TASK-1110 | 提前制定联调计划，每周进度同步 |
