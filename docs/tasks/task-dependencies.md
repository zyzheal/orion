## 依赖类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| 硬依赖 | 必须在前置任务完成后才能开始 | 数据库设计 → 表创建 |
| 软依赖 | 建议等待前置任务，但可并行 | API 定义 → Mock 实现 |
| 无依赖 | 可独立并行开发 | 独立工具函数 |

## 风险点

| 风险 | 影响任务 | 缓解措施 |
|------|----------|----------|
| NATS 集群部署延迟 | TASK-001 及后续所有任务 | 提前准备 Docker Compose 脚本，使用托管服务备选 |
| 数据库分片设计复杂 | TASK-003, TASK-1003 | 参考成熟分片方案，先单表后分片迭代 |
| Plugin SPI 技术选型 | TASK-104 | POC 验证三种方案（gRPC+WASM/HTTP+ 容器/SDK+ 进程） |
| AI 服务 GPU 资源 | TASK-301 | 协调基础设施团队，准备 CPU 降级方案 |
| 微前端集成问题 | TASK-902 | 提前验证 qiankun 与现有组件兼容性 |
