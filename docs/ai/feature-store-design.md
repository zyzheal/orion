> 版本：v1.0  
> 创建日期：2026-04-10  
> 适用范围：Orion AI 平台特征管理、训练/推理特征一致性保障

---

## 1. 背景与问题

### 1.1 特征工程现状痛点

随着 Orion AI 平台模型数量增长，特征工程面临以下核心问题：

**问题一：训练与推理特征不一致**

在现有架构中，训练阶段使用的特征计算逻辑与推理阶段存在差异，导致模型效果下降。典型案例：

| 案例 | 问题描述 | 影响 |
|------|----------|------|
| 告警聚合特征 | 训练时使用 24 小时滑动窗口，推理时使用固定时间窗口 | 模型 AUC 下降 15% |
| 日志计数特征 | 训练时包含所有日志级别，推理时过滤 DEBUG 日志 | 特征分布偏移 PSI=0.35 |
| 指标标准化 | 训练时使用全局均值/方差，推理时使用局部统计 | 预测偏差累积 |

**问题二：特征无法复用**

- 相同特征在不同模型中重复开发，计算资源浪费约 40%
- 特征口径不统一，跨团队协作成本高
- 缺乏特征血缘追踪，问题排查困难

**问题三：特征管理混乱**

- 特征定义散落在代码、配置、文档中，无统一注册
- 特征版本管理缺失，无法回滚到历史版本
- 特征质量监控不足，问题特征流入生产

### 2.2 核心组件职责

| 层级 | 组件 | 职责 | 技术选型 |
|------|------|------|----------|
| 服务层 | Feature API | 统一特征读取接口 | gRPC + Protobuf |
| 服务层 | Batch Fetch | 训练数据批量导出 | Spark Connector |
| 服务层 | Stream API | 推理特征实时获取 | Redis Client |
| 计算层 | 离线计算 | 批量特征生成与更新 | Spark 3.x |
| 计算层 | 实时计算 | 流式特征增量更新 | Flink 1.x |
| 计算层 | 转换引擎 | 特征预处理与变换 | 自研 DSL |
| 存储层 | 离线存储 | 历史特征归档 | Iceberg on HDFS |
| 存储层 | 在线存储 | 低延迟特征服务 | Redis Cluster |
| 存储层 | 元数据 | 特征注册与版本 | MySQL 8.0 |

### 4.2 特征计算 DSL 示例

```yaml
# 特征定义 YAML 示例
feature:
  id: incident_risk_score
  name: 故障风险评分
  group: risk_assessment
  version: 1.0.0
  
  # 输入依赖
  inputs:
    - feature_id: alert_count_24h
    - feature_id: metric_anomaly_score
    - feature_id: service_criticality
    
  # 转换逻辑
  transform:
    type: weighted_sum
    weights:
      alert_count_24h: 0.4
      metric_anomaly_score: 0.4
      service_criticality: 0.2
    normalization: min_max
    
  # 聚合配置
  aggregation:
    window: 1h
    function: max
    group_by: [service_id, cluster_id]
    
  # 存储配置
  storage:
    offline:
      enabled: true
      format: iceberg
      partition: [dt, hour]
    online:
      enabled: true
      ttl: 86400  # 24 小时
      
  # 质量规则
  quality:
    - rule: null_rate < 0.01
    - rule: value_range [0, 100]
    - rule: psi < 0.2
```

### 9.2 术语表

| 术语 | 定义 |
|------|------|
| Feature | 模型输入的特征变量，如告警数量、指标均值 |
| Feature Group | 特征逻辑分组，如 risk_assessment、performance |
| Point-in-Time | 时间点特征，获取指定时间戳的特征快照 |
| PSI | Population Stability Index，群体稳定性指标 |
| DSL | Domain Specific Language，领域特定语言 |
| Iceberg | Apache Iceberg，表格式存储框架 |
