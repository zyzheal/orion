# 协作空间页面功能与交互逻辑分析

> 本文档基于 Flashduty On-Call 协作空间页面（https://console.flashcat.cloud/channel）的官方文档，整理完整的功能与交互逻辑分析，用于 Orion 平台 On-Call 模块的复刻开发参考。

---

## 1. 页面架构总览

### 1.1 路由结构

```
/channel                          → 协作空间列表页
/channel/:channelId               → 协作空间详情页
  /channel/:channelId/overview    → 概览（默认 Tab）
  /channel/:channelId/incidents   → 故障列表 Tab
  /channel/:channelId/alerts      → 告警列表 Tab
  /channel/:channelId/config      → 配置页签
    → 集成数据 → 专属集成
    → 集成数据 → 排除规则
    → 降噪处理 → 告警聚合
    → 降噪处理 → 抖动检测
    → 降噪处理 → 静默策略
    → 降噪处理 → 抑制策略
    → 通知分派 → 分派策略
    → 设置 → 基础信息
    → 设置 → 高级配置
/channel/:channelId/metrics       → 指标分析页
/incidents                        → 全局故障管理（跨空间）
/alerts                           → 全局告警管理（跨空间）
/schedules                        → 值班管理
/statuspage                       → 状态页管理
/templates                        → 模板管理 / 复盘模板管理
/integrations                     → 集成中心
  /integrations/alert-events      → 告警事件（共享集成）
  /integrations/webhooks          → Webhook（故障 Webhook、Jira 同步等）
/insights                         → 分析看板
/usage                            → 用量数据
/profile                          → 个人中心 / 个人设置
```

### 1.2 页面布局

整体采用经典的 **左侧导航 + 主内容区** 布局：

| 区域 | 说明 |
|------|------|
| **左侧导航栏** | 固定侧边栏，包含：工作台、故障管理、告警管理、协作空间、值班管理、集成中心、模板管理、分析看板、状态页、平台管理 |
| **顶部栏** | 搜索框（全局故障/告警搜索）、通知铃铛、用户头像下拉菜单 |
| **主内容区** | 根据路由渲染对应页面，支持列表/详情/Drawer/Modal 等多种视图 |
| **底部栏** | 版本信息、订阅状态 |

### 1.3 导航层级

```
L1: 协作空间（菜单入口）
  └─ L2: 协作空间列表（卡片/列表视图）
      └─ L3: 协作空间详情页
          ├─ 顶部统计区域（4 张卡片）
          ├─ Tab 页签：概览 / 故障 / 告警 / 配置 / 指标分析
          └─ 配置页签内嵌侧边栏菜单
```

## 2. 协作空间列表页

### 2.1 列表展示

**视图模式**：

| 模式 | 说明 |
|------|------|
| **卡片视图**（默认） | 每个空间以卡片展示，含名称、所属团队、访问级别、最近故障时间、统计摘要 |
| **列表视图** | 表格形式展示，适合空间数量较多时 |

**卡片内容**：

| 字段 | 说明 |
|------|------|
| 空间名称 | 可点击进入详情 |
| 所属团队 | 管理团队名称 |
| 访问级别 | 公开 / 私有 标签 |
| 收藏星标 | 点击可收藏/取消收藏 |
| 最新故障时间 | 最近一次故障的触发时间 |
| 统计摘要 | MTTA、MTTR、故障数等关键指标 |

### 2.2 统计卡片

列表页顶部可展示全局统计（可选）：

| 指标 | 含义 |
|------|------|
| MTTA | 平均认领时长（触发时间 → 首次认领时间） |
| MTTR | 平均恢复时长（触发时间 → 关闭时间） |
| 故障数 | 最近 7 天触发的故障总数 |
| 告警分组 | 最近 7 天通过聚合归入同一故障的告警分组数 |

> 统计基于**最近 7 天**数据，与上一周期同比。支持折叠。

### 2.3 创建空间入口

- **位置**：列表页右上角，按钮 "创建协作空间"
- **免费版限制**：仅支持创建 1 个，超出后按钮禁用并提示升级

### 2.4 创建向导（3 步）

| 步骤 | 内容 | 可跳过 |
|------|------|--------|
| 第一步 | 协作空间信息（名称、所属团队、代管团队、访问级别、超时自动关闭、跟随告警关闭、新奇故障检测、外部提报） | 不可跳过 |
| 第二步 | 设定分派策略（通知对象、通知模板、延迟窗口、IM 群聊渠道） | 可跳过 |
| 第三步 | 接入告警事件（选择监控集成插件） | 可跳过 |

### 2.5 搜索与筛选

| 筛选项 | 说明 |
|--------|------|
| **团队筛选** | 按所属团队过滤 |
| **我收藏的** | 只看收藏的空间 |
| **搜索框** | 按空间名称模糊搜索 |
| **排序方式** | 创建时间 / 最新故障时间 / 自定义顺序 / 更新时间 / 空间名称 |
| **自定义排序** | 进入排序模式后拖拽卡片调整顺序，全局生效 |

## 3. 协作空间详情页

### 3.1 顶部统计区域

进入详情页后，顶部默认展示 4 张统计卡片（基于最近 7 天数据）：

| 卡片 | 含义 |
|------|------|
| **MTTA** | 平均认领时长 |
| **MTTR** | 平均恢复时长 |
| **故障数** | 最近 7 天故障总数 |
| **告警分组** | 聚合归入同一故障的告警分组数 |

- 支持折叠
- 点击进入"指标分析"页查看更丰富的趋势和下钻

### 3.2 Tab 页签结构

| Tab | 内容 |
|-----|------|
| **概览** | 空间基本信息 + 近期故障/告警趋势 + 快捷操作 |
| **故障** | 故障列表（继承全局故障列表能力，但限定当前空间） |
| **告警** | 告警列表（继承全局告警列表能力，但限定当前空间） |
| **配置** | 侧边栏菜单，包含集成数据、降噪处理、通知分派、设置 |
| **指标分析** | 分析看板（维度下钻、数据导出） |

### 3.3 配置页签（侧边栏菜单）

```
配置
├── 集成数据
│   ├── 专属集成（集成列表 + 添加集成）
│   └── 排除规则（规则列表 + 添加排除规则）
├── 降噪处理
│   ├── 告警聚合（智能聚合/规则聚合配置）
│   ├── 抖动检测（关闭/仅提醒/提醒后静默）
│   ├── 静默策略（规则列表 + 创建静默规则）
│   └── 抑制策略（规则列表 + 创建抑制规则）
├── 通知分派
│   └── 分派策略（策略列表 + 创建/编辑策略）
└── 设置
    ├── 基础信息（名称、描述、所属团队、代管团队、访问级别）
    └── 高级配置（超时自动关闭、跟随告警关闭、新奇故障检测、外部提报）
```

## 4. 故障管理交互

### 4.1 故障列表

**入口**：
- 协作空间详情页 → 故障 Tab
- 全局菜单 → 故障管理

**列表结构**：

| 列 | 说明 |
|----|------|
| 复选框 | 支持批量选择 |
| 严重程度 | 色条标识（Critical 红 / Warning 橙 / Info 蓝） |
| 故障标题 | 可点击进入详情 |
| 处理进度 | Triggered（待处理）/ Processing（处理中）/ Closed（已关闭） |
| 关联告警数 | 聚合的告警总数 |
| 告警事件数 | 经过聚合后累计的事件数量 |
| 触发时间 | 首次触发时间 |
| 持续时间 | 从触发到当前/关闭的时长 |
| 分派人员 | 当前处理人 |
| 协作空间 | 所属空间名称 |
| 新奇标识 | 新奇故障特殊标记 |

**筛选与搜索**：

| 筛选项 | 说明 |
|--------|------|
| **分派人员** | 分派给我 / 全部 |
| **我的协作空间** | 全部空间 / 我的空间 |
| **处理进度** | 全部 / 待处理 / 已认领 / 已关闭 |
| **时间筛选** | 相对时间（最近 24h / 7d / 30d）或自定义区间 |
| **键入检索** | 搜索故障 ID；切换到"分派给我"时同时支持模糊匹配标题 |
| **更多筛选** | 严重程度（多选）、协作空间、团队、标签（动态加载候选值）、自定义字段 |
| **告警 ID** | 支持输入多个 ID，格式错误以红色标签提示 |

> 查询性能限制：免费版最多 30 天，标准版 180 天，专业版 366 天。超过 1000 条结果仅显示 1000+。

**聚合视图**：

- 切换展示类型为"聚合"
- 顶部出现聚合规则选择器（下拉菜单）
- 支持新增/编辑/删除聚合规则
- 规则定义 Group By 维度（如按严重程度 + 协作空间 + labels.service）
- 聚合视图 URL 携带 `view_id` 参数，便于分享
- 聚合视图下最多匹配 100 条数据

**列表设置**（右上角设置按钮）：

| 选项 | 说明 |
|------|------|
| **展示类型** | 列表 / 聚合 |
| **详情展示** | 页面模式（跳转新页） / 右侧模式（右侧 Drawer 面板） |
| **自动刷新** | 关闭 / 5s / 10s / 20s / 30s / 1m / 2m / 3m / 5m / 10m |
| **展示属性** | 切换持续时间、处理人员、协作空间等列的显隐 |
| **自定义字段** | 选择平台自定义字段作为额外展示列 |
| **故障标签** | 选择或输入标签 key 作为额外展示列 |

**批量操作**：

| 操作 | 说明 |
|------|------|
| 批量认领 | 选中多个待处理故障 → 认领 |
| 批量关闭 | 选中多个故障 → 关闭 |
| 批量重新打开 | 选中多个已关闭故障 → 重新打开（需填写原因） |
| 合并 | 选中多个故障 → 合并到目标故障 |

### 4.2 故障详情页

**页面布局**：

```
┌─────────────────────────────────────────────────────┐
│ [1] 关键信息区：标题（可编辑）、严重程度（下拉切换）、    │
│     处理进度标签、ID 编号                              │
├─────────────────────────────────────────────────────┤
│ [2] 操作区域：认领 / 暂缓 / 关闭 / 更多(...) / 创建作战室  │
├──────────────┬──────────────────────────────────────┤
│ [3] 详细信息区 │ [5] 综合信息面板（右侧）                   │
│ - 故障描述     │ - 属性（协作空间、触发时间、告警数量）       │
│ - 标签信息     │ - 图片（关联告警上报的图片）               │
│ - AI 总结按钮  │ - 关键时间节点（触发/认领/关闭时间轴）      │
│ - Tab 区域 [4] │ - 处理人员（分派列表 + 认领状态）          │
│              │ - 关联链接（协作空间预配置的快捷链接）       │
│              │ - 自定义字段（展示 + 编辑）                │
│              │ - 外部工单（Jira/SN/SDP 联动工单）         │
└──────────────┴──────────────────────────────────────┘
```

**Tab 页签**（共 7 个）：

| Tab | 内容 | 显示条件 |
|-----|------|---------|
| **故障概览** | 故障摘要、关键属性、最近时间线、处理人员、关联事件 | 始终显示 |
| **关联告警** | 该故障关联的全部被聚合的告警，支持按处理进度筛选并切换视图 | alert_cnt > 0 |
| **时间线** | 完整生命周期记录 + 顶部 Markdown 评论框 | 始终显示 |
| **历史变更** | 与故障在时间上相关联的变更事件（部署/配置变更） | 始终显示 |
| **问题修复** | impact / root_cause / resolution 结构化字段 | 任一字段存在时显示 |
| **故障复盘** | 内置复盘编辑器（创建/AI生成/编辑/发布/导出） | 按订阅版本开启 |
| **历史故障** | 相似历史故障列表（最多 5 条，相似度 > 90%） | 始终显示 |

**时间线评论**：
- 顶部 Markdown 评论框
- 支持粘贴/上传图片，截图自动上传
- 评论追加到时间线，与系统事件并列展示
- 需要更新权限

**操作按钮**：

| 按钮 | 交互 |
|------|------|
| **认领** | 单个认领；批量认领；IM 应用卡片认领；语音电话按键认领 |
| **暂缓** | 下拉选择预设时长（默认 2h/4h/12h，可自定义 3 个预设，最大 24h）；暂缓期间暂停升级通知；到期自动回退待处理并重新分派 |
| **关闭** | 单个关闭；批量关闭；IM 应用卡片关闭 |
| **重新打开** | 已关闭故障点击重新打开 → Modal 弹出 → 填写重开原因（必填）→ 保存 → 回退待处理 + 重新分派通知 |
| **创建作战室** | 创建 IM 专属沟通群组 |

**更多操作菜单**（"..." 按钮）：

| 操作 | 显示条件 |
|------|---------|
| 合并至故障 | 始终显示 |
| 快速静默 | 始终显示（跳转到静默配置页并预填字段） |
| 取消认领 | 已认领且未关闭 |
| 添加关注人员进入作战室 | 已创建作战室 |
| 解散作战室 | 已创建作战室 |
| 自定义操作 | 管理员配置的 Jira/SN/SDP/通用自定义动作 |
| 故障复盘 | 已关闭且尚未生成复盘报告（快捷按钮） |

### 4.3 合并处理

| 类型 | 操作 |
|------|------|
| 故障之间合并 | 列表选中多个故障 → 合并到目标故障；或详情页选择其他目标故障合入 |
| 告警并入故障 | 告警详情页点击"并入" → 选择目标故障迁移 |

> 合并本质是改变告警与故障的关联关系。加入一个故障的告警全部并入其他故障，此故障直接关闭。时间线完整记录修改过程。

### 4.4 AI 总结

- 点击"AI 总结"按钮触发
- 基于关联告警内容（最多 20 条）生成
- 输出结构：概述 / 影响 / 建议（最多 3 条）
- 支持选择 AI 模型（默认 DeepSeek V3，可选 DeepSeek R1）
- 支持重新生成
- 流式输出
- 可保存为故障描述
- 仅自动触发的故障支持

## 5. 告警管理交互

### 5.1 告警列表

**入口**：协作空间详情页 → 告警 Tab / 全局菜单 → 告警管理

**列表结构**：

| 列 | 说明 |
|----|------|
| 复选框 | 支持批量选择 |
| 严重程度 | 色条（Critical / Warning / Info） |
| 静默/抑制标记 | 被静默或抑制的告警在标题前显示特殊图标 |
| 标题 | 可点击进入详情 |
| 处理状态 | 已恢复 / 未恢复（列表顶部支持快速筛选） |
| 故障处理进度 | 关联故障的当前处理进度 |
| 关联事件数 | 原始事件数量 |
| 关联故障 | 所属故障，点击跳转 |
| 触发时间 | 首次触发时间 |
| 集成来源 | 来源集成名称和类型（共享/专属） |
| 协作空间 | 所属空间 |

**筛选与搜索**：

| 筛选项 | 说明 |
|--------|------|
| 告警标题 | 模糊匹配 |
| 严重程度 | 多选（Critical / Warning / Info） |
| 协作空间 | 按所属空间筛选 |
| 集成 | 按来源集成筛选 |
| 标签 | 按标签键值筛选，动态加载候选值 |
| 告警 ID | 支持多个 ID，格式错误红色提示 |
| 是否被静默/抑制 | 筛选曾被静默或抑制过的告警 |

> 筛选条件按视图保留，刷新或重新进入页面后自动恢复。

**视图设置**：

| 选项 | 说明 |
|------|------|
| **详情展示** | 页面 / 右侧面板 |
| **自动刷新** | 关闭 / 5s / 10s / 20s / 30s / 1m / 2m / 3m / 5m / 10m（默认 10s） |
| **展示属性** | 恢复、故障处理进度、关联事件、关联故障、触发时间、集成来源、协作空间的显隐切换 |

**批量操作**：
- 勾选多条告警 → 点击"并入" → 选择目标故障批量并入

**聚合视图**：
- 切换到聚合视图
- 创建聚合规则（按指定维度分组）
- 左侧面板展示分组卡片（标题、严重程度、告警数量）
- 点击分组卡片 → 右侧列表展示该分组下的告警
- 最多匹配 100 条数据

### 5.2 告警详情

**HeaderInfo 信息栏**：
- 告警标题
- 严重级别标签
- 告警 ID（悬停可复制全量 ID）
- 恢复状态（已恢复 / 未恢复）
- 所属故障处理进度标签
- 静默/抑制图标（如曾被静默或抑制）
- 操作按钮："并入"（并入指定故障）

**Tab 页签**：

| Tab | 内容 |
|-----|------|
| **告警概览** | 左侧：描述、标签、关联事件预览（最多 5 条）；右侧：属性（协作空间、触发时间）、图片、告警来源、所属故障、Links |
| **关联事件** | 该告警关联的所有原始事件列表 |

**告警生命周期记录**：

| 记录类型 | 含义 |
|---------|------|
| `a_new` | 收到新告警事件，自动触发 |
| `a_update` | 收到新事件，自动更新告警 |
| `a_merge` | 告警被合并至故障 |
| `a_comm` | 发起评论 |
| `a_m_silence` | 命中静默策略，跳过通知 |
| `a_m_inhibit` | 命中抑制策略，未触发通知 |

## 6. 配置管理交互

### 6.1 集成数据

#### 专属集成

**列表页**：

**配置项**：

| 配置项 | 说明 |

**智能聚合配置**：

- 点击"重置"恢复默认

**规则聚合配置**：

## 10. 数据模型

```typescript
interface Channel {
  id: string;                    // 空间 ID

  updatedAt: Date;
```

### 10.2 故障（Incident）

```typescript
interface Incident {
  id: string;                    // 故障 ID（MongoDB ObjectId）
```

## 11. 状态机

### 11.1 故障状态流转

```
                    ┌───────────┐
                    │ Triggered │  待处理
                    │ (新建)     │
                    └─────┬─────┘
                          │ 认领 (ack)
                          ▼
                    ┌───────────┐
            ┌──────│Processing │◄─────┐
            │      │ (处理中)   │      │ 重新打开 (reopen)
            │      └─────┬─────┘      │
            │            │ 关闭        │
            │            ▼            │
            │      ┌───────────┐      │
            │      │ Closed    │──────┘
            │      │ (已关闭)   │
            │      └───────────┘
            │
            │ 暂缓超时
            │ (自动回退)
            │
            ▼
      ┌───────────┐
      │ Triggered │
      │ (重新分派) │
      └───────────┘
```

**状态转换事件**：

| 转换 | 触发操作 | 通知行为 |
|------|---------|---------|
| Triggered → Processing | 认领 (ack) | 记录时间线 |
| Processing → Closed | 关闭 (resolve) | 停止合入新告警；如开启"跟随告警关闭"则自动关闭 |
| Closed → Triggered | 重新打开 (reopen) | 重新分派通知 |
| Processing → Triggered | 暂缓超时 | 自动回退 + 重新分派通知 |
| 任意 → Processing | 新告警合入（自动） | 不触发新通知（非首次） |

### 11.2 告警状态流转

```
┌───────────┐   新事件(非Ok)   ┌───────────┐
│ Triggered │ ──────────────► │  Active   │
│ (新创建)   │                 │ (活跃)     │
└───────────┘                 └─────┬─────┘
                                    │ 恢复事件(Ok)
                                    ▼
                              ┌───────────┐
                              │ Resolved  │
                              │ (已恢复)   │
                              └───────────┘
```

> 告警状态不手动变更，由事件驱动。恢复事件（event_status=Ok）不经过 Pipeline，直接进入告警合并流程。

### 11.3 事件处理流程

```
监控系统推送事件
       │
       ▼
  ┌─────────┐
  │ 标签增强  │  ← 正则提取/组合/映射/删除
  │ Enrich  │
  └────┬────┘
       │
       ▼
  ┌─────────┐
  │ 告警处理  │  ← 修改严重程度/重写标题/丢弃/抑制
  │ Pipeline│
  └────┬────┘
       │
       ▼
  ┌─────────┐
  │ 排除规则  │  ← 按集成来源/严重程度过滤（直接丢弃）
  │ Exclude │
  └────┬────┘
       │
       ▼
  ┌──────────────┐
  │ 事件聚合       │  ← 相同 alert_key 是否合入已有告警
  │ Event Merge  │
  └────┬─────────┘
       │
       ├─ 合入已有告警 ─► 更新告警 ─► 触发 a_update 记录
       │
       └─ 新告警 ─────► 创建告警 ─► 触发 a_new 记录
                         │
                         ▼
                    ┌─────────┐
                    │ 告警聚合  │  ← 智能/规则匹配已有故障
                    │ Alert    │
                    │ Merge   │
                    └────┬────┘
                         │
                         ├─ 合入已有故障 ─► 不再通知
                         │
                         └─ 新故障 ─────► 创建故障
                                           │
                                           ▼
                                      ┌─────────┐
                                      │ 分派策略  │
                                      │ 通知      │
                                      └─────────┘
```

## 附录：关键业务规则

### A. 聚合窗口行为

| 场景 | 行为 |
|------|------|
| 事件聚合开启 | 相同 alert_key 的事件在窗口内合入同一条告警；超出窗口后创建新告警 |
| 事件聚合关闭 | 每一条事件都创建独立告警 |
| 告警聚合开启 | 相似告警在窗口内合入同一条故障 |
| 告警聚合关闭 | 每条告警创建独立故障 |

### B. 分派策略匹配

- 多条策略按优先级从上到下匹配，**匹配即停止**
- 禁用的策略跳过匹配
- 建议保留一条兜底策略（无过滤条件）

### C. 通知触发时机

| 时机 | 说明 |
|------|------|
| 首次分派 | 故障创建后按分派策略通知 |
| 重复通知 | 按设定的间隔重复通知 |
| 升级分派 | 超时后升级到下一环节处理人 |
| 重开分派 | 故障重新打开后重新分派 |

### D. 静默 vs 抑制 vs 排除 vs 暂缓

| 功能 | 生效层级 | 行为 | 是否产生记录 |
|------|---------|------|-----------|
| **排除规则** | 协作空间入口 | 直接丢弃事件 | 无任何记录 |
| **静默策略** | 协作空间 | 告警被创建但不通知/不聚合到故障 | 告警列表可标记"静默"查看 |
| **抑制策略** | 协作空间 / 集成 | 活跃告警存在时抑制相关新告警 | 告警列表可标记"抑制"查看 |
| **暂缓** | 故障级别 | 暂停升级通知，不屏蔽新告警 | 时间线记录 |

### E. 频率限制

| 资源 | 限制 |
|------|------|
| 集成 Webhook | 100 QPS / 1000 QPM |
| 故障 Webhook 回调 | 2s 超时，特定网络错误重试 1 次 |
| AI 生成 | 每分钟最多 5 次；同一报告同时只能 1 个生成任务 |

### F. 标签引用语法

| 语法 | 取值范围 | 缺失行为 |
|------|---------|---------|
| `${name}` | 仅 Labels | 返回 `<no value>` |
| `{{.Labels.name}}` | 全部属性 + Labels | 返回空字符串 |
| `{{.Title}}` / `{{.EventSeverity}}` | 属性字段 | 返回空字符串 |

### G. 过滤条件匹配逻辑

- **组内**：AND 关系（全部匹配）
- **组间**：OR 关系（任一匹配）
- **操作符**：仅 IN（匹配）/ NOTIN（不匹配）
- **匹配方式**：精确 / 正则（RE2） / 通配（*和?） / IP 段（cidr:） / 数值（num:gt:）
