# Orion 页面风格与架构设计 — 参照 Orion Visor

---

## 一、Orion Visor 项目分析

### 1.1 项目概述

**Orion Visor** 是一款开源、轻量、易用的服务器与应用管理系统，由 Gitee Dromara 社区维护。

- **Gitee**: https://gitee.com/dromara/orion-visor
- **文档**: https://www.orion-visor.site
- **定位**: 服务器与应用管理 (堡垒机替代方案)
- **Stars**: 4.1k+ (Gitee), 1.8k+ (GitHub)

### 1.2 技术栈

| 层次 | 技术 |
|------|------|
| 后端 | Spring Boot 3 + MyBatis-Plus + Sa-Token |
| 前端 | Vue3 + TypeScript + Arco Design + Pinia |
| 终端 | Xterm.js (WebSocket 终端) |
| 文件 | Monaco Editor (在线文件编辑) |
| 构建 | Vite + pnpm |
| API 文档 | SpringDoc (Swagger 3) |

### 1.3 核心功能模块

| 模块 | 功能 |
|------|------|
| 服务器管理 | 服务器批量导入、标签管理、状态监控 |
| 终端管理 | WebSocket 在线终端、多 Tab、文件上传下载、录屏回放 |
| 文件管理 | 在线文件浏览/编辑 (Monaco Editor)、下载、权限控制 |
| 脚本管理 | 脚本库、批量执行、定时任务、执行记录 |
| 审计日志 | 操作审计、终端录屏回放、登录日志 |
| 用户权限 | RBAC 权限控制、用户管理、角色管理 |

### 1.4 UI 设计特点

| 特点 | 说明 |
|------|------|
| 简洁现代 | Arco Design 组件库，干净利落的视觉风格 |
| 左侧导航 | 经典的左侧菜单 + 顶部 Header + 主内容区布局 |
| 深色终端 | 终端页面深色背景，沉浸式体验 |
| 响应式 | 适配不同屏幕尺寸 |
| 卡片式 | 内容区以卡片组织，层次清晰 |
| 状态标签 | 在线/离线/维护等状态用彩色标签标识 |
| 表格为主 | 列表页以表格为主，支持筛选/排序/分页 |

## 二、Orion (AI DevOps) 页面风格设计

### 2.1 技术栈选型

```
参照 Orion Visor 的技术栈，结合 AI DevOps 平台需求:

后端:
├── Spring Boot 3 (或保持 FastAPI + Python，视团队技术栈而定)
├── MyBatis-Plus (或 SQLAlchemy)
├── Sa-Token (或 JWT)
└── SpringDoc (Swagger 3)

前端:
├── Vue3 + TypeScript          ← 与 Orion Visor 一致
├── Arco Design (字节跳动开源)  ← 简洁现代，与 Orion Visor 一致
├── Pinia (状态管理)
├── Vue Router (路由)
└── Vite + pnpm (构建)

终端:
├── Xterm.js (在线终端)
└── Monaco Editor (代码/配置编辑)

特色组件:
├── ECharts (数据可视化)
├── D3.js (服务拓扑图)
├── Mermaid (架构图/流程图)
└── G6 (AntV 图可视化，服务依赖图)
```

### 2.3 设计风格指南

#### 配色方案

```
参照 Orion Visor 的简洁风格:

主色调: #165DFF (Arco Design 蓝色)
成功: #00B42A
警告: #FF7D00
危险: #F53F3F
信息: #86909C

背景:
├── 页面背景: #F5F6F7 (浅灰)
├── 卡片背景: #FFFFFF (白色)
├── 终端背景: #1E1E1E (深色)
└── 侧边栏: #FFFFFF 或 #F7F8FA (根据主题)

文字:
├── 主要文字: #1D2129
├── 次要文字: #4E5969
├── 辅助文字: #86909C
└── 占位文字: #C9CDD4
```

#### 组件使用规范

```
列表页:
├── 顶部: 页面标题 + 操作按钮 (新建/导入/导出)
├── 筛选区: 折叠面板，常用筛选条件
├── 表格: 支持排序/筛选/分页/批量操作
└── 底部: 分页组件

表单页:
├── 简单表单: 单列布局
├── 复杂表单: 分步表单 (Steps) 或分组 (Card)
├── 底部操作: 右对齐，主按钮 + 次按钮
└── 校验: 实时校验，错误信息红色显示

详情页:
├── 顶部: 标题 + 状态标签 + 操作按钮
├── 基本信息: Descriptions 组件
├── 详情内容: Tabs 分组
└── 时间线: Timeline 组件展示操作记录

终端页:
├── 全屏深色终端
├── 多 Tab 支持
├── 顶部工具栏 (字体大小/主题/全屏)
└── 连接状态指示
```

## 六、页面风格总结

```
Orion (AI DevOps) 页面风格 = Orion Visor 简洁风格 + DevOps 专业性

核心原则:
1. 简洁: 参照 Orion Visor, 使用 Arco Design, 干净的视觉风格
2. 专业: DevOps 平台需要展示大量数据和状态, 表格和图表为主
3. 高效: 减少点击层级, 常用操作一键可达
4. 一致: 所有页面遵循统一的设计规范

技术选型:
├── 前端: Vue3 + TypeScript + Arco Design + Pinia + Vite
├── 后端: Spring Boot 3 + MyBatis-Plus + Sa-Token
├── 终端: Xterm.js (WebSocket)
├── 编辑: Monaco Editor
├── 图表: ECharts + G6 (AntV 图可视化)
└── 文档: SpringDoc (Swagger 3)
```

---

_参照 Orion Visor (https://gitee.com/dromara/orion-visor) 的简洁风格和 Arco Design 组件库，结合 AI DevOps 平台的专业需求进行设计。_
