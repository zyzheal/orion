# Orion 外部服务集成清单

---

## 一、集成服务总览

**总计: 28 个外部服务 + 6 个微服务包装**

| 分类 | 数量 | 服务列表 |
|------|------|---------|
| 代码托管 | 3 | GitLab / GitHub / Gitee |
| 项目管理 | 3 | Jira / TAPD / Teambition |
| 文档知识库 | 3 | Confluence / Wiki.js / 语雀 |
| 认证授权 | 3 | SSO(OIDC) / SAML 2.0 / LDAP/AD |
| 即时通讯 | 4 | 钉钉 / 企业微信 / 飞书 / Slack |
| CI/CD 引擎 | 3 | Tekton / GitHub Actions / GitLab CI |
| 制品仓库 | 3 | Harbor / Nexus / JFrog |
| 可观测性 | 4 | Prometheus / Loki / Jaeger / Grafana |
| 数据库 | 2 | PostgreSQL(元数据) / MySQL(业务) |
| AI 服务 | 3 | Qwen3 / OpenAI / Claude |
| 安全扫描 | 4 | semgrep / SonarQube / Checkov / Trivy |
| 基础设施 | 5 | ArgoCD / Knative / Terraform / K8s / NATS |
| 数据库审核 | 2 | Inception / Yearning → orion-dba-svc 代理 |
| 知识库管理 | 2 | PandaWiki / Neo4j(知识图谱) |
| 运维平台 | 1 | Dromara Visor → orion-visor-svc 代理 |
| CI Runner | 1 | Orion CI Runner → orion-runner-svc(端口 3028) |

## 二、详细集成清单

### 2.1 代码托管 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| GitLab | Webhook + API | 代码仓库、PR/MR、Issue | P0 |
| GitHub | Webhook + App | 代码仓库、PR、Actions | P1 |
| Gitee | Webhook + API | 国内代码托管 | P2 |

### 2.2 项目管理 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Jira | REST API + Webhook | 需求管理、缺陷跟踪、Sprint | P0 |
| TAPD | REST API | 腾讯敏捷协作平台 | P1 |
| Teambition | REST API | 阿里项目管理 | P2 |

### 2.3 文档知识库 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Confluence | REST API + Webhook | Postmortem/Runbook 同步 | P1 |
| Wiki.js | REST API + Git 同步 | 技术文档管理 | P1 |
| 语雀 | REST API | 国内知识库 | P2 |

### 2.4 认证授权 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| SSO (OIDC) | OAuth 2.0 / OIDC | 统一认证、单点登录 | P0 |
| SAML 2.0 | SAML Protocol | 企业传统 SSO (ADFS/Ping) | P1 |
| LDAP/AD | LDAP Protocol | 内网直接对接 Active Directory | P1 |

### 2.5 即时通讯 (4 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| 钉钉 | Webhook + Bot API | 通知、ChatOps、审批 | P0 |
| 企业微信 | Webhook + Bot API | 通知、ChatOps、审批 | P0 |
| 飞书 | Webhook + Bot API | 通知、ChatOps | P1 |
| Slack | Webhook + Bot API | 国际化团队通知 | P2 |

### 2.6 CI/CD 引擎 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Tekton | K8s CRD + API | 主要 CI/CD 引擎 | P0 |
| GitHub Actions | REST API | 替代编排引擎 | P2 |
| GitLab CI | REST API | 替代编排引擎 | P2 |

### 2.7 制品仓库 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Harbor | REST API | 容器镜像存储 | P0 |
| Nexus | REST API | Java/NPM/Python 包存储 | P0 |
| JFrog | REST API | 企业级制品管理 | P2 |

### 2.8 可观测性 (4 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Prometheus | HTTP API + Federation | 指标采集、告警 | P0 |
| Loki | HTTP API | 日志聚合 | P0 |
| Jaeger | HTTP API + OpenTelemetry | 分布式追踪 | P1 |
| Grafana | Embed + API | 可视化 Dashboard | P0 |

### 2.9 数据库 (2 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| PostgreSQL | JDBC/Driver | Orion 元数据存储 | P0 |
| MySQL | JDBC/Driver | 业务数据存储、Yearning | P0 |

### 2.10 AI 服务 (3 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Qwen3 (通义千问) | HTTP API | 主要 AI 模型 | P0 |
| OpenAI | HTTP API | 备用 AI 模型 | P1 |
| Claude | HTTP API | 备用 AI 模型 | P2 |

### 2.11 安全扫描 (4 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| semgrep | CLI + API | 代码安全扫描 | P0 |
| SonarQube | Web API | 代码质量扫描 | P0 |
| Checkov | CLI | IaC 安全扫描 | P0 |
| Trivy | CLI + API | 容器/依赖扫描 | P0 |

### 2.12 基础设施 (5 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| ArgoCD | REST API + GitOps | GitOps 部署 | P0 |
| Knative | K8s CRD | 智能灰度部署 | P0 |
| Terraform | CLI + State API | 基础设施即代码 | P0 |
| Kubernetes | API Server | 容器编排平台 | P0 |
| NATS | Client Library | 事件总线 | P0 |

### 2.13 数据库审核 (2 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Inception | TCP Protocol | SQL 审核引擎 | P0 |
| Yearning (orion-dba-svc) | REST API + 微服务代理 | SQL 审核平台 → Node.js 包装服务(端口 3031) | P0 |

### 2.14 运维平台 (1 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| Dromara Visor (orion-visor-svc) | REST API + 微服务代理 | 运维主机管理/脚本/任务/终端 → Node.js 包装服务(端口 3032) | P0 |

### 2.14 知识库管理 (2 个)

| 服务 | 集成方式 | 用途 | 优先级 |
|------|---------|------|--------|
| PandaWiki | REST API + Webhook | AI 知识库管理 | P0 |
| Neo4j | Bolt Protocol | 知识图谱、服务拓扑 | P0 |
