## 技术决策记录

### 决策 1: 采用 wujie 微前端框架

**原因**:
- 支持 Vue 3 和 React 混合技术栈
- iframe 沙箱提供良好的样式和 JS 隔离
- 支持 Keep-Alive 状态保持
- 国内团队开发，文档完善

### 决策 2: orion-knowledge 采用独立部署方案

**原因**:
- Next.js SSR 与 wujie 不兼容
- 技术方案不成熟，风险高
- 独立部署 + SSO 方案风险低

### 决策 3: 保持各子应用原有 UI 库

**原因**:
- wujie 沙箱可隔离样式
- 统一 UI 库工作量巨大
- 通过 Design Tokens 统一主题色
