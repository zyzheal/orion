## 测试用例

### T01: 主应用启动测试

**目标**: 验证主应用可以正常启动

**步骤**:
1. 启动 orion-frontend
2. 访问 http://localhost:5173

**预期结果**:
- 主应用正常加载
- 控制台无错误
- 可以登录

**状态**: ⏳ 待测试

---

### T02: orion-dba 路由跳转测试

**目标**: 验证从主应用可以跳转到 orion-dba

**步骤**:
1. 登录主应用
2. 点击侧边栏"数据库管理"菜单
3. 访问 http://localhost:5173/dba

**预期结果**:
- 路由正确切换到 /dba
- orion-dba 子应用开始加载
- 容器正确渲染

**状态**: ⏳ 待测试

---

### T03: orion-dba 加载测试

**目标**: 验证 orion-dba 可以正确加载

**步骤**:
1. 访问 http://localhost:5173/dba
2. 检查浏览器控制台日志
3. 检查页面渲染

**预期结果**:
- 控制台显示 `[orion-dba] mount with props`
- 子应用正确渲染到容器中
- 样式正常显示

**状态**: ⏳ 待测试

---

### T04: Token 传递测试

**目标**: 验证主应用的 Token 正确传递给子应用

**步骤**:
1. 在主应用登录获取 Token
2. 访问 /dba 路由
3. 在子应用控制台检查 `window.$orion.token`

**预期结果**:
- Token 正确传递给子应用
- 子应用 API 调用携带正确的 Token

**状态**: ⏳ 待测试

---

### T05: 样式隔离测试

**目标**: 验证主应用和子应用样式互不干扰

**步骤**:
1. 访问主应用首页
2. 访问 /dba 路由
3. 检查主应用样式是否被影响

**预期结果**:
- 主应用样式正常
- 子应用样式正常
- 无样式污染

**状态**: ⏳ 待测试

---

### T06: 路由返回测试

**目标**: 验证从子应用可以返回主应用

**步骤**:
1. 访问 /dba 路由
2. 点击主应用菜单跳转到 /dashboard
3. 检查页面切换

**预期结果**:
- 正确切换回主应用页面
- 子应用正确卸载（或 Keep-Alive）

**状态**: ⏳ 待测试

---

### T07: 事件通信测试

**目标**: 验证主应用和子应用的事件通信

**步骤**:
1. 在子应用中调用 `window.$orion.eventBus.emit()`

3. 验证事件触发和响应

**预期结果**:
- 事件正确发送
- 事件正确接收
- 数据处理正确

**状态**: ⏳ 待测试

---

### T08: Keep-Alive 状态保持测试

**目标**: 验证子应用状态在切换时保持

**步骤**:
1. 访问 /dba 并进行操作（如滚动、表单输入）
2. 跳转到 /dashboard
3. 返回 /dba
4. 检查状态是否保持

**预期结果**:
- 页面状态保持
- 无需重新加载

**状态**: ⏳ 待测试

### T09: 错误处理测试

- 页面显示友好的错误提示
- 不影响主应用其他功能

**状态**: ⏳ 待测试
