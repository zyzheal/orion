### ✅ T07: Token 传递验证（代码审查）

**实现方式**:
1. 主应用从 localStorage 获取 Token
2. 通过 `window.$orion.token` 传递给子应用
3. 子应用通过 `getOrionConfig()` 获取 Token

**orion-dba 接收**:
```typescript
const getOrionConfig = () => {
  const orion = (window as any).$orion || {};
  return {
    token: orion.token || sessionStorage.getItem('jwt'),
    apiBase: orion.getApiBase?.() || '/api/v2',
  };
};
```

**验证结果**:
- ✅ Token 传递链路正确
- ✅ 请求拦截器配置正确
- ✅ X-Orion-Token Header 设置正确
