### 2.2 TenantScope 拦截器

```go
// Repository 层统一租户拦截器
type TenantScope struct {
    TenantID string
}

func (ts *TenantScope) Apply(ctx context.Context, query *sqlx.SelectExecQuerier) {
    if ts.TenantID == "global" || ts.TenantID == "" {
        return // 公共知识，不过滤
    }
    query.Where("tenant_id = ?", ts.TenantID)
}

// 所有 RAG 查询必须经过 TenantScope
func (r *Repository) Search(ctx context.Context, query string) ([]Node, error) {
    scope := TenantScopeFromContext(ctx) // 从 context 提取 tenant_id
    scope.Apply(ctx, &q)
    return q.Find()
}
```

### 3.1 LWW + Vector Clock 策略

### 3.2 分布式锁（全量对账时）

```go
// PostgreSQL Advisory Lock 防止并发全量对账
func acquireBuildLock(ctx context.Context, db *sqlx.DB, source string) (bool, error) {
    var locked bool
    err := db.GetContext(ctx, &locked,
        "SELECT pg_try_advisory_xact_lock(hashtext($1))", source)
    return locked, err
}

// 使用方式
func (b *Builder) Reconcile(ctx context.Context, source string) error {
    locked, err := acquireBuildLock(ctx, b.db, source)
    if !locked {
        return ErrBuildInProgress // 另一实例正在构建，跳过
    }
    defer releaseBuildLock(ctx, b.db, source)
    return b.doReconcile(ctx, source)
}
```

## 六、ACL 权限模型统一（P1-4 修复）

```
现有 Orion ACL 模型:
  aclMiddleware: { resource: "pipeline", action: "delete", role: "admin" }

RAG 元数据格式:
  { "required_role": "admin", "tenant_scoped": true, "visibility": "private" }

映射规则:
  ACL resource:action → RAG metadata.required_action
  ACL role          → RAG metadata.required_role
  ACL tenant_id     → RAG metadata.tenant_id

索引构建时:
  从 handler_registry_entries.config 读取 ACL 配置
  → 直接映射为 RAG 元数据（不引入 max_role_level 新概念）
```
