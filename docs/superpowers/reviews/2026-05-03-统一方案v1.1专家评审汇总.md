## 七、关键技术方案补充

### 7.1 幻觉检测方案（数据AI专家补充）

```
#13c 幻觉/安全检测 (5人月)
技术方案:
1. 置信度阈值过滤: confidence < 0.7 触发人工审查
2. Self-consistency投票: 同一请求调用3次，响应不一致率>30%标记高风险
3. RAG知识库验证: Patch修改的API调用需在文档库中存在定义
4. 安全边界检查: 禁止删除文件、禁止修改认证相关代码、禁止引入新依赖
```

### 7.2 LLM语义缓存修正（数据AI专家补充）

```
#12b LLM语义缓存层 (修正版)
工作量: 3.5人月 (原2人月)
预期命中率: 12-18% (原20-30%过于乐观)
年节省: ¥180k-280k (原¥300k-500k偏高)

技术方案:
1. Redis存储缓存键(向量hash) + 响应
2. 近似最近邻搜索(FAISS/HNSW)而非精确匹配
3. TTL=24h + 冷数据LRU淘汰
4. 租户隔离: cache_key = tenant_id + embedding_hash
```
