### 9.2 缓解措施补充

**AI Autofix(#13)缓解措施**:
```
1. 结构化校验前置(#49): Patch必须合法JSON/YAML
2. 幻觉检测(#13子项):
   - 置信度<0.7触发人工审查
   - Self-consistency 3次投票，不一致率>30%标记高风险
   - RAG知识库验证API调用定义存在
   - 安全边界检查: 禁止删除文件、禁止修改认证代码、禁止引入新依赖
3. 沙箱验证强制: K8s隔离命名空间+资源限制+网络隔离
4. 渐进发布: 1%→5%→25%→50%→100%流量控制
5. 自动回滚: 验证失败立即回滚，审计日志记录
```

**LLM缓存(#12b)缓解措施**:
```
1. 命中率预期调整: 12-18%而非20-30%
2. FAISS/HNSW近似匹配而非精确匹配
3. TTL=24h + 冷数据LRU淘汰
4. 租户隔离: cache_key = tenant_id + embedding_hash
5. 年节省预期: ¥180k-280k而非¥300k-500k
```
