## 七、AI Autofix工作量修正说明

### 7.1 v1.3错误表述

**v1.3声称**: "AgentSandbox-2+#49前置-0.5+#51升P0-0.5 = 30人月"

**问题**：
- #49前置是依赖关系调整，不直接减少工作量
- #51升P0是优先级调整，不减少工作量

### 7.2 v1.4正确表述

| 分项 | v1.2 | v1.4 | 调整原因 |
|------|:----:|:----:|----------|
| LLM Patch生成 | 6人月 | **6人月** | 无变化 |
| 沙箱验证 | 8人月 | **6人月** | **AgentSandbox.ts(170行)复用-2人月** |
| 幻觉检测 | 5人月 | **7人月** | Self-consistency投票+安全边界检查+2人月(风险缓冲) |
| UI | 4人月 | **4人月** | 无变化 |
| 渐进发布 | 6人月 | **6人月** | 无变化 |
| 回滚 | 3人月 | **3人月** | 无变化 |
| **合计** | 32人月 | **32人月** | 沙箱-2 + 幻觉+2 = 32人月 |

**净调整**: AgentSandbox复用(-2) + 幻觉风险缓冲(+2) = **32人月**（持平但有风险缓冲）
