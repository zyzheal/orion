## 一、页面概述

### 1.1 页面定义

流水线创建向导是一个多步骤表单流程，引导用户完成流水线的配置。采用分步设计降低认知负荷，每步聚焦单一任务，支持随时预览和返回修改。

### 1.2 目标用户

| 角色 | 核心任务 | 使用频率 | 专业程度 |
|------|----------|----------|----------|
| 开发工程师 | 创建新流水线、配置 Stage | 中频（每周 2-5 次） | 中等 |
| DevOps 工程师 | 复杂流水线配置、模板复用 | 高频（每日 5-10 次） | 高 |
| 技术主管 | 审核和标准化配置 | 低频（每周 1-2 次） | 高 |

### 1.3 设计原则

- **渐进披露**：每步仅展示必要信息，避免信息过载
- **进度可见**：清晰显示当前步骤和剩余步骤
- **错误预防**：实时验证，错误在提交前发现
- **灵活导航**：支持任意步骤跳转、暂存草稿

## 六、交互说明

### 6.1 Step 1: 基本信息

| 字段 | 类型 | 必填 | 验证规则 | 错误提示 |
|------|------|------|----------|----------|
| 流水线名称 | 文本输入 | 是 | 3-64 字符，`/^[a-z0-9-]+$/` | "名称只能包含小写字母、数字和连字符" |
| 所属产品线 | 下拉选择 | 是 | 必须选择 | "请选择产品线" |
| 描述 | 多行文本 | 否 | 最多 500 字符 | "描述不能超过 500 字符" |
| 触发方式 | 复选框组 | 是 | 至少选 1 项 | "请至少选择一个触发方式" |

**实时验证反馈**：
- 名称输入时实时查重，重复显示 "该名称已被使用"
- 字符数实时计数，显示 `x/64`
- 描述字数接近限制时（450+）变黄提醒
