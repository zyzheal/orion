## 四、修复建议

### 高优先级（影响核心功能）

1. **防重复提交**
   ```typescript
   // 在 handleCreate 中添加
   const [submitting, setSubmitting] = useState(false);
   
   const handleCreate = async (values) => {
     if (submitting) return;
     setSubmitting(true);
     try {
       // ... 提交逻辑
     } finally {
       setSubmitting(false);
     }
   };
   ```

2. **配额使用量展示**
   - 调用 `getTenantUsage()` API
   - 使用 Progress 组件展示使用率
   - 超过 80% 红色警告

3. **删除后刷新列表**
   ```typescript
   const handleDelete = async (id) => {
     await deleteTenant(id);
     message.success('租户已删除');
     loadTenants(); // 添加这行
   };
   ```

### 中优先级（影响体验）

4. 表格增加排序/筛选
5. 增加搜索框
6. 配额页面增加进度条可视化

### 低优先级（锦上添花）

7. 批量操作
8. 模板创建
9. 导出功能
