## 四、修正后的实施路线（20周，6个核心组件）

### 第零阶段：数据持久化补齐（4-6周）- 无外部依赖

0. **Repository 迁移** (4-6周)
   - 40 个服务域从 Map() 迁移到 PostgreSQL Repository 模式
   - 数据持久化覆盖率从 46% 提升至 100%
   - 当前已有 30+ 服务完成迁移，作为参考模板

### 第一阶段：安全与监控基础（4周）- P0

1. **Prometheus + Grafana** (2周)
   - `fastify-metrics` 集成导出 Prometheus 格式指标
   - Grafana 部署 + 监控大屏
   - 前端 iframe 嵌入 Grafana（不自建 UI）

2. **Vault 密钥管理** (2周)
   - 动态密钥生成（数据库凭据、API Key）
   - 与现有 K8sSecretKeyStorage 集成
   - 前端 iframe 嵌入 Vault UI（不自建）

### 第二阶段：认证增强与缓存（6周）- P0+P1

3. **Keycloak 身份联邦** (4周)
   - OAuth2/OIDC 联邦登录（企业微信/钉钉/LDAP）
   - SSO 单点登录
   - 前端 SSO 跳转（不自建 Keycloak Admin UI）

4. **Redis Sentinel** (2周)
   - 主从部署 + 自动故障切换
   - ioredis 适配
   - 无需 Cluster（125K keys/12.5K QPS 单节点足够）

### 第三阶段：网关与 CI/CD 可视化（4周）- P1

5. **Kong 或 K8s Ingress** (2周)
   - 评估 Kong vs K8s Ingress Controller
   - 与现有自研 Gateway 的流量路由策略
   - 明确替换或共存方案

6. **CI/CD Pipeline 可视化前端** (2周)
   - 已有后端 41 文件支持
   - 流水线列表、一键触发、日志实时查看
   - 部署历史与回滚界面

### 第四阶段：审计加固与集成测试（6周）- P1

7. **后端统一审计中间件** (2周)
   - Fastify hook 记录所有 POST/PUT/DELETE
   - 操作人、时间、变更前后值
   - 不可篡改的审计日志流

8. **PostgreSQL RLS 租户隔离** (2周)
   - 核心业务表启用 `ALTER TABLE ... ENABLE ROW LEVEL SECURITY`
   - 租户隔离从 API 层下沉到数据库层
   - 双重防护：应用层 + 数据库层

9. **全链路集成测试** (2周)
   - 组件间集成测试
   - 性能测试
   - 用户验收
