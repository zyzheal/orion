### 1.3 truth-report 的前端文件统计错误

truth-report 第 20-21 行声称前端有 739 个 .tsx 文件和 345 个 .ts 文件。实际：
- `.tsx` 文件: **638** (偏差 101)
- `.ts` 文件: **14** (偏差 331)

345 这个数字很可能是把 `stores/` (9) + `hooks/` + `router/` (2) + `utils/` 等非页面 .ts 文件都算进去了。而 739 是 total .ts/.tsx 文件数 (638+14=652 不对... 让我核实)。

实际上 638+14=652，不是 739。739 可能是包含了 components 目录的 108 文件 (92+16=108)，652+108=760 也不对。

**结论**: truth-report 的前端文件统计需要重新核实。

### 3.2 结论: full-report 不够全面

**优势**:

- 缺少 truth-report 的 temporal coupling 分析
- 缺少 truth-report 的 PageRank 热点文件分析
- 缺少持久化迁移的详细批次信息 (deep-analysis 有)
