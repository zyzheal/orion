# Orion 最小系统启动指南

> 本文档说明如何从零启动 Orion 平台，包含**最小可运行系统**和**全量系统**两种模式。
> 适用场景：本地开发、新成员 onboarding、环境排查。

---

## 一、前置依赖

### 必须安装

| 依赖 | 版本 | 用途 |
|------|------|------|
| **Node.js** | >= 20.x | 后端 + 前端运行时 |
| **npm** | >= 10.x | 包管理 |
| **PostgreSQL** | >= 14 | 主数据库 |
| **Git** | >= 2.x | 代码管理 |

### 可选依赖

| 依赖 | 用途 | 不安装的影响 |
|------|------|-------------|
| **Redis** | Token/Session 缓存 | 服务会打印 warning，继续运行（无缓存） |
| **NATS** | 事件总线 | 使用内存 EventBus，事件不跨进程 |

## 二、最小可运行系统（仅核心）

最小系统只需启动 **2 个服务**：PostgreSQL + Platform Service。前端可跳过。

### 2.1 启动顺序

```
1. PostgreSQL  →  2. orion-platform-service
```

### 2.2 详细步骤

#### Step 1: 启动 PostgreSQL

```bash
# 本地开发可用 Docker
docker run -d \
  --name orion-postgres \
  -e POSTGRES_USER=orion \
  -e POSTGRES_PASSWORD=orion123 \
  -e POSTGRES_DB=orion \
  -p 5432:5432 \
  postgres:16-alpine

# 或使用本地已安装的 PostgreSQL
# psql -U postgres -c "CREATE DATABASE orion;"
```

#### Step 2: 执行数据库迁移

```bash
cd orion-platform-service

# 手动执行 migration（或使用项目内迁移脚本）
psql -U orion -h localhost -d orion -f src/db/migrations/001_create_*.sql
psql -U orion -h localhost -d orion -f src/db/migrations/002_*.sql
# ... 依次执行 001-055

# 或使用一键迁移（如果项目有迁移脚本）
# npm run migrate
```

#### Step 3: 启动 Platform Service

```bash
cd orion-platform-service

# 安装依赖
npm install

# 配置环境变量（复制或创建 .env）
cp .env.example .env 2>/dev/null || echo "使用默认配置"

# 启动开发模式（watch 热重载）
npm run dev

# 启动后应看到:
# 🚀 Orion Platform Service
# ✅ Server is running
# 📍 Address: http://localhost:3001
# 🏥 Health: http://localhost:3001/healthz
```

#### Step 4: 验证

```bash
# 健康检查
curl http://localhost:3001/healthz

# 应返回: {"status":"ok"} 或类似响应
```

**此时系统已可用**：可以通过 API 直接访问 Platform Service（端口 3001）。

## 三、完整系统启动（推荐开发模式）

完整系统包含前端 + 网关 + 后端 + 数据库，适合日常开发。

### 3.1 启动顺序

```
1. PostgreSQL  →  2. Redis (可选)  →  3. orion-platform-service  →  4. orion-api-gateway  →  5. orion-frontend
```

> **重要**：必须先启动后端服务，再启动前端。前端开发服务器启动时会检查后端连通性。

### 3.2 详细步骤

#### Step 1: PostgreSQL + Redis

```bash
# PostgreSQL
docker run -d --name orion-postgres \
  -e POSTGRES_USER=orion \
  -e POSTGRES_PASSWORD=orion123 \
  -e POSTGRES_DB=orion \
  -p 5432:5432 \
  postgres:16-alpine

# Redis (可选)
docker run -d --name orion-redis \
  -p 6379:6379 \
  redis:7-alpine
```

#### Step 2: 数据库迁移

```bash
cd orion-platform-service

# 执行所有 migration
for f in src/db/migrations/0[0-5][0-9]_create_*.sql; do
  psql -U orion -h localhost -d orion -f "$f"
done
```

#### Step 3: 启动 Platform Service

```bash
cd orion-platform-service
npm install
npm run dev
# → http://localhost:3001
```

#### Step 4: 启动 API Gateway

```bash
cd orion-api-gateway
npm install
npm run dev
# → http://localhost:3000
# Gateway 会将请求代理到 Platform Service (3001)
```

#### Step 5: 启动前端

```bash
cd orion-frontend
npm install
npm run dev
# → http://localhost:5173 (Vite 默认端口)
```

#### Step 6: 验证全链路

```
浏览器打开: http://localhost:5173
         ↓
    前端 React App
         ↓ (API 请求)
    API Gateway (localhost:3000)
         ↓ (代理)
    Platform Service (localhost:3001)
         ↓ (查询)
    PostgreSQL (localhost:5432)
```

## 四、带子应用的完整启动

如果需要开发/调试微前端子应用，需额外启动对应服务。

### 4.1 子应用启动

```
基础链路 (上述 5 步)  →  6. orion-dba / orion-knowledge / orion-visor
```

#### orion-dba (数据库管理)

```bash
cd orion-dba
# 结构: backend/ + frontend/

# 启动前端 (Vue3 + Ant Design Vue)
cd frontend
npm install
npm run dev
# → http://localhost:3001
```

#### orion-knowledge (知识库)

```bash
cd orion-knowledge
# 这是一个独立项目，可能需要 docker-compose 启动

# 查看 docker-compose
cat docker-compose.yaml

# 启动
docker-compose up -d
# → http://localhost:3002
```

#### orion-visor (运维监控)

```bash
cd orion-visor
# 结构: backend/ + web/ (Vue3 + Arco Design)

# 启动前端
cd web
npm install
npm run dev
# → http://localhost:3003
```

### 4.2 主应用配置

确保 `orion-frontend/src/microfront/apps.ts` 中的子应用 URL 与实际端口一致：

```typescript
const APP_BASE_URLS: Record<string, string> = {
  'dba': 'http://localhost:3001',
  'knowledge': 'http://localhost:3002',
  'visor': 'http://localhost:3003',
};
```

## 五、环境变量配置

### orion-platform-service/.env

```env
# 数据库
DB_HOST=localhost
DB_PORT=5432
DB_USER=orion
DB_PASSWORD=orion123
DB_NAME=orion

# Redis (可选)
REDIS_HOST=localhost
REDIS_PORT=6379

# NATS (可选)
NATS_ENABLED=false
NATS_SERVERS=nats://localhost:4222

# JWT
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=1h
JWT_REFRESH_EXPIRES_IN=7d

# 服务端口
PORT=3001
```

### orion-api-gateway/.env

```env
# Platform Service 地址
PLATFORM_SERVICE_URL=http://localhost:3001

# JWT (需与 Platform Service 一致)
JWT_SECRET=your-secret-key

# 网关端口
PORT=3000
```

## 六、常见问题

### Q: Platform Service 启动后报数据库连接错误

```
⚠️  Database connection failed, continuing without Database
```

**原因**：PostgreSQL 未启动或配置错误。
**解决**：检查 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD` 是否正确。

### Q: 前端无法访问 API

**原因**：Vite proxy 配置指向错误的后端地址。
**解决**：检查 `orion-frontend/vite.config.ts` 中的 proxy 配置，确保指向 `localhost:3001` 或 `localhost:3000`（Gateway）。

### Q: 子应用加载失败

**原因**：子应用未启动或 URL 配置错误。
**解决**：
1. 确认子应用在对应端口运行
2. 检查 `microfront/apps.ts` 中的 `APP_BASE_URLS` 配置
3. 浏览器开发者工具 Network 面板查看具体失败原因

### Q: 热重载不生效

**原因**：tsx watch 可能需要重启。
**解决**：`Ctrl+C` 停止后重新 `npm run dev`。

## 八、一键启动脚本（推荐）

在项目根目录创建 `start.sh`：

```bash
#!/bin/bash
# Orion 一键启动脚本

echo "🚀 Starting Orion Platform..."

# 1. 检查 PostgreSQL
if ! pg_isready -h localhost -p 5432 -q 2>/dev/null; then
  echo "📦 Starting PostgreSQL..."
  docker start orion-postgres 2>/dev/null || \
  docker run -d --name orion-postgres -e POSTGRES_USER=orion -e POSTGRES_PASSWORD=orion123 -e POSTGRES_DB=orion -p 5432:5432 postgres:16-alpine
fi

# 2. 启动 Platform Service
echo "🔧 Starting Platform Service..."
cd orion-platform-service
npm run dev &
PLATFORM_PID=$!
cd ..

# 3. 等待 Platform Service 启动
sleep 3

# 4. 启动 API Gateway
echo "🌐 Starting API Gateway..."
cd orion-api-gateway
npm run dev &
GATEWAY_PID=$!
cd ..

sleep 2

# 5. 启动前端
echo "🎨 Starting Frontend..."
cd orion-frontend
npm run dev &
FRONTEND_PID=$!
cd ..

echo ""
echo "✅ Orion Platform started!"
echo "   Frontend: http://localhost:5173"
echo "   Gateway:  http://localhost:3000"
echo "   Platform: http://localhost:3001"
echo ""
echo "Press Ctrl+C to stop all services."

# 捕获退出信号
trap "kill $PLATFORM_PID $GATEWAY_PID $FRONTEND_PID" EXIT
wait
```
