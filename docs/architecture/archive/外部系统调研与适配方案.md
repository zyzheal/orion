## 一、调研概述

本次调研针对三个需要接入 wujie 微前端架构的外部子应用系统：
- `orion-dba` - 数据库管理系统
- `orion-knowledge` - 知识库系统
- `orion-visor` - 监控中心系统

### 调研目标

1. 分析各系统技术栈和架构特点
2. 评估 wujie 适配可行性
3. 制定详细的迁移改造方案
4. 识别潜在风险和应对措施

---

## 二、系统技术栈分析

### 2.1 orion-dba

| 维度 | 详情 |
|------|------|
| **框架** | Vue 3.2.39 |
| **UI 库** | Ant Design Vue 3.2.15 |
| **状态管理** | Vuex 4.x + vuex-persistedstate |
| **路由** | Vue Router 4.x |
| **构建工具** | Vite |
| **语言** | TypeScript |
| **CSS 方案** | Less |

**关键特性**:
- 已支持微前端模式 (`dev:mf`, `build:mf` 脚本)
- 支持独立运行/微前端嵌入双模式
- 使用 Ant Design Vue 与主应用 Ant Design React 存在 UI 库差异

**适配方案**:
- ✅ 保持 Vue 3 技术栈，使用 wujie iframe 沙箱接入
- ✅ 无需 UI 库统一，wujie 沙箱可隔离样式
- ✅ 已有微前端构建配置，只需适配 wujie 生命周期

**改造工作量**: 2-3 天

## 三、wujie 适配可行性评估

### 3.1 技术兼容性

| 系统 | 框架兼容性 | UI 库兼容性 | 沙箱兼容性 | 总体评估 |
|------|-----------|-----------|-----------|---------|
| orion-dba | ✅ Vue 3 完美支持 | ✅ 沙箱隔离 | ✅ 已有 MF 经验 | 高 |
| orion-knowledge | ✅ React 完美支持 | ✅ 沙箱隔离 | ⚠️ 需配置 UMD | 中高 |
| orion-visor | ✅ Vue 3 完美支持 | ✅ 沙箱隔离 | ⚠️ 重型组件需测试 | 中高 |

### 3.2 wujie 支持特性

- ✅ Vue 3 应用支持
- ✅ React 应用支持
- ✅ iframe 沙箱隔离
- ✅ 样式隔离
- ✅ JS 沙箱
- ✅ 预加载
- ✅ Keep-Alive 状态保持
- ✅ 子应用生命周期管理
- ✅ 主应用 ↔ 子应用通信

### 3.3 潜在风险

| 风险项 | 影响系统 | 风险等级 | 应对措施 |
|--------|---------|---------|---------|
| UI 库差异导致视觉不一致 | 全部 | 低 | 通过 Design Tokens 统一主题色 |
| Xterm 终端沙箱兼容性 | orion-visor | 中 | 提前测试，必要时降级方案 |
| ECharts 性能问题 | orion-visor | 低 | 虚拟滚动 + 按需渲染 |
| MUI 与 AntD 样式冲突 | orion-knowledge | 低 | 沙箱隔离 |
| 路由跳转冲突 | 全部 | 中 | 统一路由前缀管理 |

### 4.2 子应用入口规范 (F202)

所有子应用需要遵循统一的接入规范：

#### 4.2.1 双模式支持

```javascript
// 独立运行模式
if (window.__POWERED_BY_WUJIE__) {
  // 微前端嵌入模式
  export const bootstrap = () => { ... }
  export const mount = () => { ... }
  export const unmount = () => { ... }
} else {
  // 独立运行
  createApp(App).mount('#app')
}
```

#### 4.2.2 生命周期导出

```typescript
// wujie 子应用生命周期
export async function bootstrap() {
  console.log('子应用启动')
}

export async function mount(props: Record<string, unknown>) {
  // 接收主应用注入的 props
  console.log('子应用挂载', props)
  // 挂载应用到指定容器
}

export async function unmount() {
  console.log('子应用卸载')
}
```

#### 4.2.3 Props 接收规范

子应用应接收以下标准 props：
- `$orion.user` - 用户信息
- `$orion.token` - 认证 Token
- `$orion.theme` - 主题
- `$orion.eventBus` - 事件总线
- `$orion.getApiBase` - API 基础路径方法

#### 4.2.4 构建配置

```typescript
// vite.config.ts - UMD 输出
export default {
  build: {
    rollupOptions: {
      output: {
        format: 'umd',
        name: 'OrionSubApp',
        entry: 'src/main.ts',
      },
    },
  },
}
```

### 4.4 联调测试 (F206)

#### 测试清单

| 测试项 | 测试内容 | 通过标准 |
|--------|---------|---------|
| 路由跳转 | 主应用 ↔ 子应用路由切换 | 无刷新切换，状态保持 |
| 状态共享 | 用户信息、Token 传递 | 子应用可正常访问 |
| 样式隔离 | 各应用样式互不干扰 | 无样式污染 |
| 通信协议 | 主应用 ↔ 子应用事件通信 | 事件正常触发和响应 |
| 性能回归 | 首屏加载时间、内存占用 | 相比独立运行差异 < 20% |

## 六、总结

### 6.1 技术选型结论

- **wujie 框架**: 完全满足需求，支持 Vue 3/React 混合技术栈
