### 关键事实

| 维度 | 文档设计（理想态） | 当前实际实现 |
|------|-------------------|-------------|
| **后端架构** | 8 个 Java 微服务 | **1 个 Node.js/Fastify 单体** |
| **API 路由** | 分散在各微服务 | **48 个 route 文件**，集中注册 |
| **控制器** | 分散在各服务 | **42 个 Controller**，同一进程 |
| **服务层** | 按域拆分 | **70+ Service**，同一进程 |
| **数据层** | 多数据库分片 | **统一 PostgreSQL**，70 migrations |
| **前端技术栈** | Vue3 + Arco + Module Federation | **React 18 + Vite + Ant Design 5** |
| **微前端** | 7 个子应用 | **3 个子应用**（wujie） |
| **前端页面** | 分散在 monorepo packages | **57+ 页面**，集中在 orion-frontend |
| **服务间通信** | NATS + Istio 网格 | **进程内调用**（无网络开销） |

## 四、模块间调用关系

### 4.1 请求链路

```
用户浏览器
    │
    ▼
┌─────────────────────────────────┐
│  API Gateway (orion-api-gateway) │
│  Fastify, 端口: 3000             │
│  ├── /healthz                    │
│  ├── /version                    │
│  └── 反向代理 → Platform Service │
└──────────────┬──────────────────┘
               │ (HTTP)
               ▼
┌─────────────────────────────────┐
│  Platform Service (单体)         │
│  Fastify, 端口: 3001             │
│  │                               │
│  ├─ routes.ts (48 路由模块)      │
│  │   ↓                           │
│  ├─ Controllers (42 个)          │
│  │   ↓                           │
│  ├─ Services (70+ 个)            │
│  │   ↓                           │
│  ├─ Repositories (38 个)         │
│  │   ↓                           │
│  └─ PostgreSQL (连接池)          │
└─────────────────────────────────┘
```

### 4.2 进程内调用（非网络调用）

由于后端是单体架构，所有服务间调用都是**进程内函数调用**，不存在网络开销：

```
Controller → Service → Repository → PostgreSQL
    ↑           ↑          ↑
    │           │          │
    └─── 同一 Node.js 进程 ─┘
```

### 4.3 前端路由分发

```
React Router v6
├── /                     → 首页/控制台

├── /pipelines/*          → 流水线页面 (主应用渲染)
├── /tickets/*            → 工单页面 (主应用渲染)
├── /dba/*                → DBA 页面 (wujie → orion-dba)
├── /knowledge/*          → 知识库页面 (wujie → orion-knowledge)
├── /visor/*              → 监控页面 (wujie → orion-visor)
└── /... (50+ routes)     → 其他页面 (主应用渲染)
```
