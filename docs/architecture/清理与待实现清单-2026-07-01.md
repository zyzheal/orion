## 三、AI 服务 Python 化（特殊路径）

**`orion-ai-svc` (TS, 19,599 行)** 不走 Go 迁移，而是扩充 **`orion-ai-service` (Python)**：

| 步骤 | 说明 | 工作量 |
|------|------|--------|
| 扩充 Python 版 | 覆盖 AI Gateway、MultiAgentOrchestrator、MLInferenceService | 极高 |
| API 对齐 | 确保 Python 版与前端调用路径一致 | 高 |
| 废弃 TS 版 | Python 版完全覆盖后，删除 `orion-ai-svc/` | — |

**保留的 Node.js 服务**（不移入 Go）：
| 服务 | 理由 |
|------|------|
| `orion-platform-service` | 主单体，120 模块，迁移成本极高 |
| `orion-api-gateway` | 轻量网关，Node.js/Fastify 足够 |
| `orion-frontend` | React/Vite，与后端语言无关 |
