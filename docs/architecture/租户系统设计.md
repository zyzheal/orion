## 一、需求理解

### 1.1 业务背景

Orion 定位为 DevOps 平台，支持多团队/多客户使用。需要租户系统实现：
- 资源隔离：不同租户的数据、计算、网络完全隔离
- 配额控制：每个租户可使用的资源有上限
- 弹性扩展：支持从小团队单租户拆分到多租户
- 灵活配置：各功能可按需启用/禁用

### 1.2 核心需求

| 需求 | 描述 | 优先级 |
|-----|------|-------|
| 租户管理 | 创建、编辑、删除租户 | P0 |
| 配额管理 | 配置和监控租户资源配额 | P0 |
| Namespace 动态管理 | 按需创建/释放 Namespace（非固定池） | P0 |
| 多租户切换 | 用户可切换当前所属租户 | P0 |
| 单租户简化 | 只有一个租户时隐藏选择器 | P1 |
| 子租户支持 | 支持租户层级结构（可配置） | P2 |
| 配额告警 | 使用量超阈值发送通知（可配置） | P2 |
| 用户邀请 | 邀请用户加入租户（可配置） | P2 |
| 计费模式 | 按配额计费（可配置） | P3（MVP 暂不实现） |

> **优先级说明**：MVP 阶段聚焦核心租户隔离功能，计费模块（P3）可后续迭代。

## 二、概念定义

### 2.1 租户 (Tenant)

```
租户 = 团队 / 部门 / 项目组 / 客户公司

定位灵活性：
- 小团队：整个团队用一个租户
- 大企业：按部门/子公司创建多个租户
- SaaS：每个客户一个租户
```

### 2.2 租户与用户关系

```
多对多关系：一个用户可以属于多个租户

tenant_users 表：
┌──────────┬──────────┬────────┐
│ tenant_id│ user_id  │ role   │
├──────────┼──────────┼────────┤
│ acme     │ user-1   │ owner  │
│ acme     │ user-2   │ member │
│ acme-sales│ user-2  │ member │  ← 用户同时属于两个租户
└──────────┴──────────┴────────┘

角色说明：
- owner: 租户所有者，可管理租户所有设置
- admin: 租户管理员，可管理用户和资源
- member: 普通成员，使用资源
```

### 2.3 配额 (Quota)

```
配额 = 租户可使用的资源上限

资源项：
├── maxPipelines: 最大 Pipeline 数量
├── maxPipelineRunsPerDay: 每日最大运行次数
├── maxConcurrentRuns: 最大并发运行数
├── maxRunners: 最大 Runner Pod 数量
├── maxCpuCores: CPU 核心数上限
├── maxMemoryGb: 内存上限 (GB)
├── maxStorageGb: 存储上限 (GB)
└── maxNamespaces: 最大 Namespace 数量
```

### 2.4 Namespace 管理

```
动态 Namespace 管理（非固定池）

设计考量：
- 固定池（100个）限制租户数量上限，不适合大规模扩展
- 动态按需创建，自动释放，更灵活

分配策略：
- 每个租户最多分配 maxNamespaces 个 Namespace（默认 10）
- Namespace 命名：{tenant-name}-{uuid-short}，如 acme-corp-a1b2c
- 状态：active（活跃）/ releasing（释放中）/ released（已释放）
- 释放时执行 Kubernetes 资源清理（保留 24 小时回收期）

回收机制：
- 租户删除时，Namespace 进入 releasing 状态
- 24 小时后自动删除（或手动立即删除）
- 释放配额计数立即归还，使用量归零
```

## 三、可配置功能说明

### 3.1 子租户支持（Hierarchy）

**功能描述**：支持租户创建子租户，形成层级结构

**配置项**：
| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| enabled | boolean | false | 是否启用子租户功能 |
| maxDepth | number | 2 | 最大层级深度 |

**使用场景**：
- 大型企业：母公司 → 子公司 → 部门 → 小组
- 项目制公司：总公司 → 项目部 → 项目组

**继承规则**：
- 子租户继承父租户的部分配额（可自定义比例）
- 子租户可以有自己的独立 Namespace
- 资源使用量汇总到父租户统计

### 3.2 配额告警（Alerts）

**功能描述**：配额使用达到阈值时发送通知

**配置项**：
| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| enabled | boolean | false | 是否启用告警 |
| thresholdPercent | number | 80 | 告警阈值百分比 |
| notifyOnThreshold | number[] | [80, 100] | 触发通知的阈值列表 |
| notificationMethods.inApp | boolean | true | 站内通知 |
| notificationMethods.email | boolean | false | 邮件通知 |
| notificationMethods.webhook | boolean | false | Webhook 回调 |
| notificationMethods.sms | boolean | false | 短信通知 |
| webhookUrl | string | - | Webhook 地址 |

**告警触发示例**：
```json
{
  "tenantId": "acme",
  "resourceType": "runners",
  "currentUsage": 4,
  "quotaLimit": 5,
  "thresholdPercent": 80,
  "message": "租户 ACME 的 Runner 配额使用已达 80% (4/5)"
}
```

### 3.3 用户邀请（Invites）

**功能描述**：邀请新用户加入租户

**配置项**：
| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| enabled | boolean | true | 是否启用邀请功能 |
| requireEmailVerification | boolean | false | 是否需要邮件验证 |
| requireAdminApproval | boolean | false | 是否需要管理员审批 |
| inviteExpiryHours | number | 72 | 邀请链接有效期（小时） |
| maxInvitesPerDay | number | 50 | 每日最大邀请次数 |

**邀请流程**：
1. 管理员输入用户邮箱、角色（admin/member）
2. 系统生成邀请码并发送邮件
3. 用户点击链接接受邀请
4. 根据配置决定是否需要邮件验证或审批
5. 用户关联到租户

### 3.4 计费模式（Billing）

> **状态**：MVP 暂不实现，P3 后续迭代

**功能描述**：基于配额或实际使用量计费

**配置项**（MVP 暂不支持）：
| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| enabled | boolean | false | 是否启用计费（P3 实现） |
| billingModel | string | 'quota' | 计费模型：quota/usage/hybrid |
| billingCycle | string | 'monthly' | 计费周期：monthly/daily/hourly |
| pricing.perPipeline | number | 10 | 每个 Pipeline 月费 |
| pricing.perRunner | number | 20 | 每个 Runner 月费 |
| pricing.perCpuCore | number | 5 | 每核 CPU 月费 |
| pricing.perMemoryGb | number | 2 | 每 GB 内存月费 |
| pricing.perStorageGb | number | 0.5 | 每 GB 存储月费 |
| pricing.perNamespace | number | 5 | 每个 Namespace 月费 |
| freeQuota.pipelines | number | 5 | 免费 Pipeline 数 |
| freeQuota.runners | number | 2 | 免费 Runner 数 |
| freeQuota.cpuCores | number | 4 | 免费 CPU 核数 |
| freeQuota.storageGb | number | 10 | 免费存储 GB |
| overageMultiplier | number | 1.5 | 超额使用倍数 |

**计费模型说明**：
- `quota`：按配额上限计费（不管实际是否使用）
- `usage`：按实际使用量计费
- `hybrid`：基础费（按配额）+ 超额费（按实际使用）

**后续迭代计划**：
- Phase 1：配额计费（quota model）
- Phase 2：实际使用量计费（usage model）
- Phase 3：混合计费 + 账单管理

## 四、数据模型设计

### 4.1 核心表结构

```sql
-- 租户表
CREATE TABLE tenants (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name            VARCHAR(100) NOT NULL UNIQUE,    -- 租户标识，如 acme-corp
  display_name    VARCHAR(200),                     -- 显示名称，如 ACME 公司
  parent_id       UUID REFERENCES tenants(id),     -- 父租户 ID（子租户功能）
  depth           INTEGER NOT NULL DEFAULT 1,      -- 租户层级深度
  status          VARCHAR(20) NOT NULL DEFAULT 'active',  -- active/inactive/deleted
  settings        JSONB NOT NULL DEFAULT '{}',     -- 扩展配置（含功能开关）
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 用户-租户关联表
CREATE TABLE tenant_users (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id   UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
  user_id     UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  role        VARCHAR(50) NOT NULL DEFAULT 'member',  -- owner/admin/member
  is_default  BOOLEAN NOT NULL DEFAULT FALSE,         -- 用户默认进入的租户
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(tenant_id, user_id)
);

-- 租户配额表
CREATE TABLE tenant_quotas (
  id                    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id             UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
  max_pipelines         INTEGER NOT NULL DEFAULT 100,
  max_pipeline_runs_per_day INTEGER NOT NULL DEFAULT 1000,
  max_concurrent_runs   INTEGER NOT NULL DEFAULT 10,
  max_tasks_per_pipeline INTEGER NOT NULL DEFAULT 50,
  max_runners           INTEGER NOT NULL DEFAULT 5,
  max_cpu_cores         INTEGER NOT NULL DEFAULT 16,
  max_memory_gb         INTEGER NOT NULL DEFAULT 32,
  max_storage_gb        INTEGER NOT NULL DEFAULT 100,
  max_namespaces        INTEGER NOT NULL DEFAULT 10,
  api_rate_limit        INTEGER NOT NULL DEFAULT 1000,
  api_rate_limit_window_seconds INTEGER NOT NULL DEFAULT 60,
  usage                 JSONB NOT NULL DEFAULT '{}',  -- 当前使用量
  created_at            TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at            TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Namespace 管理表（动态创建）
CREATE TABLE namespace_allocations (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  namespace_name  VARCHAR(100) NOT NULL UNIQUE,   -- acme-corp-a1b2c
  cluster_id      VARCHAR(100) NOT NULL DEFAULT 'default',
  tenant_id       UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
  status          VARCHAR(20) NOT NULL DEFAULT 'active',  -- active/releasing/released
  purpose         VARCHAR(100),                     -- 用途说明
  labels          JSONB NOT NULL DEFAULT '{}',
  allocated_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  released_at     TIMESTAMPTZ,                     -- 计划删除时间（24小时后）
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 租户邀请表
CREATE TABLE tenant_invites (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id       UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
  email           VARCHAR(255) NOT NULL,
  role            VARCHAR(50) NOT NULL DEFAULT 'member',
  invite_code     VARCHAR(64) NOT NULL UNIQUE,
  status          VARCHAR(20) NOT NULL DEFAULT 'pending',  -- pending/accepted/expired
  invited_by      UUID NOT NULL REFERENCES users(id),
  accepted_by     UUID REFERENCES users(id),
  expires_at      TIMESTAMPTZ NOT NULL,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
  accepted_at     TIMESTAMPTZ
);

-- 配额告警记录表
CREATE TABLE tenant_quota_alerts (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id       UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
  resource_type   VARCHAR(50) NOT NULL,           -- runners/pipelines/cpu等
  threshold_percent INTEGER NOT NULL,              -- 触发阈值
  current_usage   INTEGER NOT NULL,                -- 当前使用量
  quota_limit     INTEGER NOT NULL,                -- 配额上限
  notify_status   VARCHAR(20) NOT NULL DEFAULT 'sent',  -- sent/pending/failed
  cooldown_until  TIMESTAMPTZ,                      -- 冷却截止时间
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 租户账单表（P3 实现）
-- CREATE TABLE tenant_bills ( ... );
```

### 7.4 配额告警触发逻辑

```typescript
interface QuotaAlertConfig {
  enabled: boolean;
  thresholdPercent: number;       // 默认 80
  notifyOnThreshold: number[];    // [80, 100]
  cooldownMinutes: number;        // 冷却期，默认 60 分钟
}

// 触发逻辑
function checkQuotaAlert(tenantId, resourceType, usage, limit) {
  const percent = (usage / limit) * 100;
  const config = getTenantAlertConfig(tenantId);

  if (!config.enabled) return;

  // 检查是否在通知阈值列表
  const shouldNotify = config.notifyOnThreshold
    .some(threshold => percent >= threshold);

  if (!shouldNotify) return;

  // 检查冷却期，避免重复通知
  const lastAlert = getLastAlert(tenantId, resourceType);
  if (lastAlert && lastAlert.cooldownUntil > now()) {
    return; // 冷却期内，不重复通知
  }

  // 发送通知
  sendAlert(tenantId, resourceType, percent, usage, limit);
}
```

## 十、计费示例（P3 后续实现）

> MVP 阶段不实施，代码保留仅供参考

### 10.1 费用计算

```typescript
// 配置
const pricing = {
  perPipeline: 10,    // $10/个/月
  perRunner: 20,      // $20/个/月
  perCpuCore: 5,      // $5/核/月
};

const freeQuota = {
  pipelines: 5,
  runners: 2,
  cpuCores: 4,
};

// 租户实际使用
const usage = {
  pipelines: 10,
  runners: 5,
  cpuCores: 16,
};

// 月费计算
const calculateMonthlyBill = (usage, pricing, freeQuota) => {
  let total = 0;
  
  // Pipeline 费用
  const freePipelines = Math.max(0, freeQuota.pipelines);
  const billablePipelines = Math.max(0, usage.pipelines - freePipelines);
  total += billablePipelines * pricing.perPipeline;
  
  // Runner 费用
  const freeRunners = Math.max(0, freeQuota.runners);
  const billableRunners = Math.max(0, usage.runners - freeRunners);
  total += billableRunners * pricing.perRunner;
  
  // CPU 费用
  const freeCores = Math.max(0, freeQuota.cpuCores);
  const billableCores = Math.max(0, usage.cpuCores - freeCores);
  total += billableCores * pricing.perCpuCore;
  
  return total;
};

// 结果
// = (10-5) × $10 + (5-2) × $20 + (16-4) × $5
// = $50 + $60 + $60
// = $170/月
```

```typescript
// TenantManagement/index.tsx - 使用 getTenantUsage API
import { getTenantUsage } from '@/api/tenant';

const [usage, setUsage] = useState<TenantUsage | null>(null);

useEffect(() => {
  loadData();
}, []);

const loadData = async () => {
  const usageRes = await getTenantUsage();
  setUsage(usageRes.data.usage);
};

// 在配额卡片中展示
{quotaItems.map((item) => {
  const used = usage?.[item.key]?.used || 0;
  const percent = (used / item.value) * 100;
  return (
    <div>
      <Progress percent={percent} strokeColor={
        percent > 80 ? colors.error[500] :
        percent > 60 ? colors.warning[500] :
        colors.success[500]
      } />
      <Text>{used} / {item.value} {item.unit}</Text>
    </div>
  );
})}
```
