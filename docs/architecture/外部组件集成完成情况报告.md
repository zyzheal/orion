## 一、集成概述

本次更新将 3 个外部成熟开源组件整合到 Orion 平台系统设计中，遵循"增强而非替代"的设计原则，通过微服务 + 微前端架构实现松耦合集成。

### 1.1 外部组件清单

| 组件 | 定位 | 集成方式 | 技术栈 | 许可证 | GitHub Stars |
|------|------|---------|--------|--------|-------------|
| **orion-visor** | CMDB 服务器/应用/终端管理 | 微前端 + API 集成 | Java + Vue3 | Apache-2.0 | 3.3k+ |
| **orion-dba** | SQL 审计 (基于 Yearning 改造) | 可插拔插件 | Go + Vue3 | Apache-2.0 | - |
| **orion-knowledge** | 知识库/RAG 问答 | 可插拔微服务 | Go + React/Next.js | AGPL-3.0 | - |

### 1.2 Build vs Integrate 决策

| 模块 | 决策 | 理由 |
|------|------|------|
| **CMDB** | ✅ 集成 orion-visor | 成熟开源方案 (3.3k+ stars)，功能完整，避免重复造轮子 |
| **SQL 审计** | ✅ 改造 Yearning 为 orion-dba | 基于 Yearning 3.3k+ stars，深度 Orion 集成，微前端化 |
| **知识库** | ✅ 集成 orion-knowledge | 已有完整 RAG 能力，Orion 专注 AI 增强 |

## 二、orion-dba 改造说明

### 2.1 改造背景

**原始方案**: 独立部署 Yearning + gemini-next，通过 API Gateway 集成

**问题**:
- Yearning 和 gemini-next 分散在两个目录，管理复杂
- gemini-next 前端代码在 Yearning 仓库外，版本同步困难
- 无法深度集成 Orion 认证和权限系统

**改造方案**: 
- 删除 Yearning 和 gemini-next 独立目录
- 将 gemini-next 改造为 orion-dba/frontend（微前端子应用）
- Yearning 后端代码复制到 orion-dba/backend
- 前端支持独立运行和嵌入 Orion 两种模式

### 2.2 改造内容

| 项目 | 改造前 | 改造后 |
|------|--------|--------|
| **目录结构** | `Yearning/` + `gemini-next/` | `orion-dba/backend/` + `orion-dba/frontend/` |
| **前端架构** | 独立应用 (gemini-next) | 微前端子应用 (qiankun) |
| **认证方式** | JWT Token | Orion Token (X-Orion-Token) |
| **权限系统** | Yearning 内置 RBAC | Orion RBAC 集成 |
| **构建输出** | 独立 HTML | UMD 格式 (orion-dba-app.js) |
| **许可证** | AGPL-3.0 | Apache-2.0 (前端) / 保留 Yearning AGPL (后端) |

### 2.3 项目结构

```
orion-dba/
├── backend/                 # Go 后端 (基于 Yearning 代码)
│   ├── handler/            # 业务处理器
│   ├── model/              # 数据模型
│   ├── router/             # 路由配置
│   ├── engine/             # SQL 审核引擎
│   ├── lib/                # 工具库
│   ├── apis/               # API 接口
│   ├── service/            # 服务层
│   ├── i18n/               # 国际化
│   ├── internal/           # 内部扩展 (预留)
│   └── pkg/                # 公共包 (预留)
├── frontend/                # Vue3 前端 (原 gemini-next 改造)
│   ├── src/
│   │   ├── apis/           # API 封装
│   │   ├── components/     # 公共组件
│   │   ├── config/         # 配置文件
│   │   ├── views/          # 页面组件 (11 个)
│   │   ├── main.ts         # 入口 (支持微前端)
│   │   └── App.vue         # 根组件
│   ├── vite.config.ts      # 微前端构建配置
│   └── package.json
├── plugin.yaml              # Orion 插件描述文件
└── README.md
```

### 2.4 微前端集成

**独立运行模式** (开发环境):
```bash
$ cd orion-dba/frontend
$ yarn install
$ yarn dev
# 访问：http://localhost:3010
```

**微前端模式** (生产环境，嵌入 Orion):
```typescript
// main.ts
if (window.__POWERED_BY_ORION__) {
  export async function mount(props) {
    instance = createApp(props);
    instance.mount('#orion-dba-app');
  }
}
```

**Orion 全局状态注入**:
```typescript
app.config.globalProperties.$orion = {
  user: props.user,
  permissions: props.permissions,
  token: props.token,
  apiBase: props.apiBase || '/api/v1/db',
};
```

### 4.2 API Gateway 路由

```yaml
routes:
  # CMDB API
  - path: /api/v1/cmdb/*
    service: orion-visor-service:8080
    strip_prefix: true
    
  # SQL 审计 API
  - path: /api/v1/db/*
    service: orion-dba-service:8090
    strip_prefix: true
    
  # 知识库 API
  - path: /api/v1/knowledge/*
    service: orion-knowledge-service:8300
    strip_prefix: true
```
