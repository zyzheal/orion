    ┌─────────────┐
    │   Monitor   │  动态基线监控 (Prophet)
    │    Agent    │  异常检测 (XGBoost + DBSCAN)
    └──────┬──────┘
           │ 异常检测到
           ▼
    ┌─────────────┐
    │  Diagnose   │  PageRank 根因定位 (服务依赖图)
    │    Agent    │  RAG 匹配历史故障库
    └──────┬──────┘  LLM 生成诊断报告
           │
           ▼
    ┌─────────────┐
    │   Decide    │  修复方案评估 (风险/成本/时间)
    │    Agent    │  审批流决策 (自动/人工)
    └──────┬──────┘  Human-in-the-Loop
           │
    ┌──────┴──────┐
    │  审批通过？  │
    └──────┬──────┘
       是/否
       ┌─┴─┐
       ▼   ▼
    ┌───────┐  ┌─────────┐
    │Execute│  │ 升级    │
    │ Agent │  │ On-Call │
    └───┬───┘  └─────────┘
        │  沙箱验证
        │  执行修复
        ▼
    ┌─────────────┐
    │   Verify    │  效果验证
    │    Agent    │  指标回归检测
    └──────┬──────┘
           │
           ▼
    ┌─────────────┐
    │  Feedback   │  写入知识库
    │    Agent    │  模型再训练
    └─────────────┘
