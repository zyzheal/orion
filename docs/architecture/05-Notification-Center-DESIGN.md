## 一、页面概述

### 1.1 页面定义

通知中心是 Orion 平台的统一通知管理界面，聚合流水线状态、审批请求、系统公告等各类通知，支持筛选、批量操作和个性化设置。页面强调信息优先级和高效处理。

### 1.2 目标用户

| 角色 | 核心任务 | 使用频率 | 关注通知类型 |
|------|----------|----------|--------------|
| 开发工程师 | 查看构建结果、审批进度 | 高频（每日 20+ 次） | 流水线/审批 |
| 运维工程师 | 监控部署状态、系统告警 | 高频（每日 50+ 次） | 告警/部署 |
| 技术主管 | 审批请求、团队动态 | 中频（每日 5-10 次） | 审批/报告 |
| 产品经理 | 发布进度、项目动态 | 低频（每日 2-3 次） | 发布/公告 |

### 1.3 设计原则

- **优先级清晰**：紧急通知醒目，普通通知不干扰
- **分类明确**：按类型、状态智能分组
- **操作高效**：批量处理、一键已读
- **可定制化**：支持订阅管理和免打扰

## 六、交互说明

### 6.1 筛选器交互

**筛选条件**：

| 筛选器 | 选项 | 多选 | 默认值 |
|--------|------|------|--------|
| 类型 | 流水线/审批/部署/系统/其他 | 是 | 全部 |
| 状态 | 未读/已读/归档 | 是 | 未读 |
| 分类 | 全部/我的收藏/提及我 | 否 | 全部 |
| 优先级 | P0/P1/P2/P3 | 是 | 全部 |
| 时间 | 今天/最近 7 天/最近 30 天/自定义 | 否 | 最近 7 天 |

**筛选行为**：
- 筛选条件变更时，列表无刷新加载
- 筛选条件保存在 URL 参数，支持分享
- 点击"清除筛选"重置所有条件

| 操作 | 数量 | 确认方式 | 可撤销 |

### 6.5 实时通知推送

**推送行为**：
- 新通知到达时，右上角 Badge 数字 +1
- 未读通知 >99 时，显示 "99+"
- 重要通知（P0/P1）显示桌面提醒（如已启用）
- 免打扰期间，P0 通知仍可推送
